# 新电脑上传到GitHub指南

## 概述
由于项目迁移到了新电脑，需要重新配置Git环境并上传到GitHub的11.19分支。

## 前置要求

### 1. 安装Git
如果还没有安装Git，请从 [git-scm.com](https://git-scm.com/download/win) 下载并安装。

### 2. 准备GitHub信息
你需要知道：
- GitHub用户名
- GitHub邮箱
- GitHub仓库URL（例如：`https://github.com/username/LLM-values.git`）

### 3. GitHub认证设置
由于GitHub已不再支持密码认证，你需要使用以下方式之一：

#### 方式A: Personal Access Token (推荐)
1. 访问 GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
2. 点击 "Generate new token (classic)"
3. 设置权限：勾选 `repo` (完整仓库访问权限)
4. 生成并保存token（只显示一次！）
5. 推送时使用token作为密码

#### 方式B: SSH密钥
```powershell
# 生成SSH密钥
ssh-keygen -t ed25519 -C "your_email@example.com"

# 复制公钥
Get-Content ~/.ssh/id_ed25519.pub | Set-Clipboard

# 然后到GitHub Settings → SSH and GPG keys → New SSH key
# 粘贴公钥并保存
```

## 快速上传方法

### 自动化脚本（推荐）

我已经为你创建了一个PowerShell脚本，它会自动完成所有配置和上传步骤：

```powershell
# 在PowerShell中运行
cd "e:\Code\value of LLM\LLM's values"
.\setup_and_upload.ps1
```

脚本会提示你输入：
1. GitHub用户名
2. GitHub邮箱
3. GitHub仓库URL

然后自动完成：
- Git初始化
- 用户配置
- 远程仓库配置
- 创建11.19分支
- 添加和提交文件
- 推送到GitHub

### 手动步骤

如果你想手动执行，按以下步骤操作：

#### 步骤1: 配置Git用户信息
```powershell
git config --global user.name "你的GitHub用户名"
git config --global user.email "你的GitHub邮箱"
```

#### 步骤2: 初始化Git仓库
```powershell
cd "e:\Code\value of LLM\LLM's values"
git init
```

#### 步骤3: 添加远程仓库
```powershell
# 替换为你的实际仓库URL
git remote add origin https://github.com/username/repo.git

# 验证远程仓库
git remote -v
```

#### 步骤4: 拉取远程分支信息
```powershell
# 如果仓库已存在，先拉取远程信息
git fetch origin

# 查看所有分支
git branch -a
```

#### 步骤5: 创建并切换到11.19分支
```powershell
# 如果远程已有update-1119分支
git checkout -b update-1119 origin/update-1119

# 如果远程没有，创建新分支
git checkout -b update-1119
```

#### 步骤6: 清理缓存并添加文件
```powershell
# 清理之前可能跟踪的大文件
git rm -r --cached . 2>$null

# 添加所有文件（.gitignore会自动排除大文件）
git add .
```

#### 步骤7: 检查状态
```powershell
# 查看将要提交的文件
git status

# 查看文件数量
git status --short | Measure-Object
```

#### 步骤8: 提交更改
```powershell
git commit -m "更新项目：迁移到新电脑后的首次提交

- 更新项目文件到最新状态
- 添加.gitignore排除大文件和model_cultural_comp-main
- 包含最新的分析结果和文档
- 排除超大数据文件（可通过脚本重新生成）"
```

#### 步骤9: 推送到GitHub
```powershell
# 首次推送到新分支
git push -u origin update-1119
```

如果推送失败，可能需要先拉取远程更改：
```powershell
git pull origin update-1119 --rebase
git push -u origin update-1119
```

## 常见问题解决

### 问题1: 推送时要求认证

**解决方案A: 使用Personal Access Token**
```powershell
# 推送时，用户名输入GitHub用户名
# 密码输入Personal Access Token（不是GitHub密码！）
git push -u origin update-1119
```

**解决方案B: 配置凭据管理器**
```powershell
# Windows会自动保存凭据
# 首次输入token后，后续推送不需要再输入
```

### 问题2: 仍然有大文件被拒绝

```powershell
# 查看哪些大文件被添加
git ls-files -s | ForEach-Object {
    $parts = $_ -split '\s+'
    $size = [int]$parts[3]
    $file = $parts[4]
    if ($size -gt 10000000) {
        "$file - $([math]::Round($size/1MB, 2))MB"
    }
}

# 从暂存区移除大文件
git reset HEAD <文件路径>

# 更新.gitignore，添加该文件路径
# 然后重新提交
git add .
git commit --amend
git push -f origin update-1119
```

### 问题3: 远程分支冲突

```powershell
# 拉取远程更改并变基
git pull origin update-1119 --rebase

# 如果有冲突，解决后继续
git add .
git rebase --continue

# 推送
git push origin update-1119
```

### 问题4: 需要强制推送

```powershell
# 谨慎使用！只在确认本地版本正确时使用
git push -f origin update-1119
```
