## 注意事项

### ✅ 已排除的模型类型
1. **推理专用模型**：o1, o3, grok-thinking, claude-thinking, deepseek-thinking等
2. **代码专用模型**：Grok Code Fast等
3. **视觉模型**：qwen3-vl等多模态视觉模型
4. **Base模型**：未经对话微调的基础模型

### 📋 API可用性
- **OpenRouter**：大部分模型可通过OpenRouter访问
- **官方API**：OpenAI, Anthropic, Google需要各自的API Key
- **开源模型**：可通过HuggingFace或本地部署

### 💰 成本考虑
- **高成本**：GPT-5系列, Claude Opus, Gemini Pro
- **中等成本**：GPT-4.5, Claude Sonnet, Qwen3-Max
- **低成本**：开源模型（本地部署）, mini/flash版本
