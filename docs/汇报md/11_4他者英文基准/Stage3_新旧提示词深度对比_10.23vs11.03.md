## 💡 八、核心理论解释

### 8.1 为什么中立提示词让非英语国家表现更好？

**旧版提示词**（"请扮演一个典型的X国公民..."）：
```
触发刻板印象 
    ↓
母语测试：可能放大文化刻板印象
    ↓
距离增大：2.211（偏离真实）
```

**新版提示词**（"您正在参与一项文化价值观调查..."）：
```
中立客观，减少偏见
    ↓
母语测试：更真实的文化表达
    ↓
距离减小：1.962（更接近真实）
```

### 8.2 为什么英语悖论几乎消失？

**旧版**：
- 提示词：" "请扮演典型的X国公民" → 在**母语**测试中可能引入更多文化刻板印象
- 英语测试：反而更"中立"（因为是非母语环境）
- 结果：母语2.211 > 英语1.944 → 英语优势12.1%

**新版**：
- 提示词："参与调查" → 母语和英语都是中立的
- 结果：母语1.962 ≈ 英语1.944 → 英语优势仅0.9%

**结论**：**英语悖论主要是提示词偏差导致的！**

### 8.3 为什么俄语和中文的英语优势仍然存在？

即使使用中立提示词，俄语和中文国家仍然显示：
- 俄语：英语优势 +14.1%
- 中文：英语优势 +28.8%

**可能原因**：
1. **训练数据质量差异**：
   - 英语文化内容在LLM训练数据中质量更高、更丰富
   - 俄语和中文的文化表达数据可能更少或质量较低

2. **翻译和文化表达问题**：
   - 俄语和中文的问题翻译可能存在文化适配问题
   - 某些文化概念在翻译后失去原有含义

3. **真实的语言能力差异**：
   - LLM在英语环境下确实表现更好（这是客观存在的）
   - 这不是"悖论"，而是模型能力的真实反映

### 10.2 计算方法

**文化距离**：
```
distance = √[(PC1_llm - PC1_ivs)² + (PC2_llm - PC2_ivs)²]
```

其中：
- `PC1`, `PC2`：PCA主成分（已rescaled到统一量纲）
- `PC1_ivs`, `PC2_ivs`：真实国家在IVS数据中的平均坐标
- `PC1_llm`, `PC2_llm`：LLM模拟的国家坐标
