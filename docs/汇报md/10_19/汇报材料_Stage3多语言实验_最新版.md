### Slide 5: 评估方法

**内容**：
```
如何评估准确度？

评估准确度方法：文化距离（Cultural Distance）

Distance = √[(PC1_LLM - PC1_Country)² + (PC2_LLM - PC2_Country)²]

📏 距离越小 = 模仿越准确
📏 距离越大 = 偏离真实文化

对比方式：
┌──────────────┐    ┌──────────────┐
│  母语距离    │ vs │  英语距离    │
│              │    │              │
│   中文→      │    │   英语→      │
│   LLM        │    │   LLM        │
│   回答中国   │    │   回答中国   │
└──────────────┘    └──────────────┘
         ↓                 ↓
      1.94              1.03
      
结果：英语距离更小 = 英语更准确！（47%优势）

预期：母语距离 < 英语距离
实际：大多数情况下 英语距离 < 母语距离 ❗
```
