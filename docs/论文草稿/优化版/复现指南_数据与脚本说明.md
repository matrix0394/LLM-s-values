## 2. 英语优势计算方法

### 2.1 核心公式

```
英语优势 = (母语距离 - 英语距离) / 母语距离 × 100%

解释：
- 正值 = 英语提示更好（英语优势）
- 负值 = 母语提示更好（母语优势）
```

### 2.2 距离计算

```
距离 = √[(LLM_PC1 - IVS_PC1)² + (LLM_PC2 - IVS_PC2)²]
```

### 2.3 计算步骤

**步骤1：排除低质量模型**
```python
EXCLUDED_MODELS = ['qwen3-1.7b']  # 排除低质量模型
```

**步骤2：排除英语母语国家的en数据，使用en-native**
```python
# 英语母语国家列表
en_native_countries = [
    'Australia', 'Canada', 'Ghana', 'Hong Kong', 'Ireland', 'Kenya',
    'Malaysia', 'Malta', 'New Zealand', 'Nigeria', 'Pakistan',
    'Philippines', 'Puerto Rico', 'Rwanda', 'Singapore',
    'South Africa', 'Trinidad and Tobago', 'United Kingdom',
    'United States of America', 'Zambia', 'Zimbabwe'
]

# 香港特殊处理：使用en-native（因为数据中没有en，只有en-native）
# 香港母语是zh-hk（粤语），不是zh-cn
if country == 'Hong Kong':
    english_lang = 'en-native'
    native_lang = 'zh-hk'  # 粤语
```

**步骤3：关键！先平均距离，再计算优势**
```python
# 错误方法（会导致完全不同结果）：
for model in models:
    adv = 100 * (d_native - d_en) / d_native  # 每个模型计算优势
    advantages.append(adv)
avg_advantage = np.mean(advantages)  # 再平均

# 正确方法（论文使用的方法）：
for model in models:
    d_en_list.append(d_en)  # 收集所有模型的距离
    d_native_list.append(d_native)
    
avg_en = np.mean(d_en_list)  # 先平均距离
avg_native = np.mean(d_native_list)
advantage = 100 * (avg_native - avg_en) / avg_native  # 再计算优势
```

## 3. 复现代码示例

### 3.1 完整复现脚本

```python
import pandas as pd
import numpy as np

# 1. 加载数据
csv_data = pd.read_csv('SI/pca/Table_S7_LLM_roleplay_PCA_coordinates.csv')
ivs_json = pd.read_json('data/country_values/country_scores_pca.json')
ivs_json = ivs_json.drop_duplicates(subset=['Country'])
ivs_coords = ivs_json.set_index('Country')[['PC1_rescaled', 'PC2_rescaled']].to_dict('index')

# 2. 排除低质量模型
csv_data = csv_data[csv_data['model_name'] != 'qwen3-1.7b']

# 3. 国家-语言映射（从论文结果文件获取）
# 论文对多语言国家（瑞士、比利时等）计算了多种语言
# 注意：
#   - 香港的母语是粤语(zh-hk)，不是简体中文(zh-cn)
#   - 台湾使用繁体中文(zh-tw)
#   - 澳门使用简体中文(zh-cn)和葡萄牙语(pt)
native_lang_multi = {
    'China': [('China', 'zh-cn')],
    'Taiwan, Province of China': [('Taiwan, Province of China', 'zh-tw')],  # 繁体中文
    'Hong Kong': [('Hong Kong', 'zh-hk'), ('Hong Kong', 'zh-cn')],  # 粤语和简体中文
    'Macao': [('Macao', 'zh-cn'), ('Macao', 'pt')],  # 简体中文和葡萄牙语
    'Tunisia': [('Tunisia', 'ar')],
    'Jordan': [('Jordan', 'ar')],
    'Switzerland': [('Switzerland', 'de'), ('Switzerland', 'fr'), ('Switzerland', 'it')],
    # ... 其他国家
}

# 4. 判断英语类型（en vs en-native）
def get_english_lang(country_name):
    en_native_countries = ['Australia', 'Canada', 'Ghana', 'Hong Kong', 'Ireland', 'Kenya', 
                           'Malaysia', 'Malta', 'New Zealand', 'Nigeria', 'Pakistan', 
                           'Philippines', 'Puerto Rico', 'Rwanda', 'Singapore', 
                           'South Africa', 'Trinidad and Tobago', 'United Kingdom', 
                           'United States of America', 'Zambia', 'Zimbabwe']
    if country_name == 'Hong Kong':
        return 'en-native'
    if country_name in en_native_countries:
        return 'en-native'
    return 'en'

# 5. 计算英语优势
results = []
for country, langs in native_lang_multi.items():
    for country_name, native_lang in langs:
        if country_name not in ivs_coords:
            continue
        
        ivs_pc1, ivs_pc2 = ivs_coords[country_name]['PC1_rescaled'], ivs_coords[country_name]['PC2_rescaled']
        
        english_lang = get_english_lang(country_name)
        
        en_rows = csv_data[(csv_data['country'] == country_name) & (csv_data['language'] == english_lang)]
        native_rows = csv_data[(csv_data['country'] == country_name) & (csv_data['language'] == native_lang)]
        
        if len(en_rows) == 0 or len(native_rows) == 0:
            continue
        
        # 逐模型收集距离
        en_dists = []
        native_dists = []
        for model in en_rows['model_name'].unique():
            en_m = en_rows[en_rows['model_name'] == model]
            native_m = native_rows[native_rows['model_name'] == model]
            
            if len(en_m) == 0 or len(native_m) == 0:
                continue
            
            en_pc1, en_pc2 = en_m['PC1'].mean(), en_m['PC2'].mean()
            native_pc1, native_pc2 = native_m['PC1'].mean(), native_m['PC2'].mean()
            
            d_en = np.sqrt((en_pc1 - ivs_pc1)**2 + (en_pc2 - ivs_pc2)**2)
            d_native = np.sqrt((native_pc1 - ivs_pc1)**2 + (native_pc2 - ivs_pc2)**2)
            
            en_dists.append(d_en)
            native_dists.append(d_native)
        
        if len(en_dists) > 0 and len(native_dists) > 0:
            # 先平均距离，再计算优势（关键！）
            avg_en = np.mean(en_dists)
            avg_native = np.mean(native_dists)
            
            if avg_native > 0:
                advantage = 100 * (avg_native - avg_en) / avg_native
                results.append({
                    'country': country_name,
                    'native_language': native_lang,
                    'english_advantage': advantage
                })

results_df = pd.DataFrame(results)
print(f"平均英语优势: {results_df['english_advantage'].mean():.1f}%")
```

## 5. 关键注意事项

### 5.1 数据源一致性
- **必须使用** `country_scores_pca.json` 中的IVS坐标（不是SI CSV文件）
- SI CSV中的坐标略有不同，会导致数值差异

### 5.2 模型过滤
- 必须排除 `qwen3-1.7b`（低质量模型）

### 5.3 en vs en-native
- 英语母语国家（21个）使用 `en-native`
- 非英语国家使用 `en`
- 香港特殊处理：使用 `en-native`

### 5.4 计算顺序
- **先平均距离，再计算优势**
- 不要先计算优势再平均

### 5.5 多语言国家
- 瑞士、比利时、卢旺达等多语言国家需要分别计算每种语言
- 然后在区域汇总时取平均
