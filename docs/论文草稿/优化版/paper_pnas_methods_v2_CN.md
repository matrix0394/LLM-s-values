# 材料与方法

## 概述

我们开展了四项研究来表征大型语言模型中嵌入的人类价值观及其与现实世界文化价值观的一致性。研究1估计LLMs的内在价值取向并与IVS基准进行比较。研究2调查文化表征中的语言依赖性差异，测试英语与官方语言提示是否系统性地影响一致性准确度。研究3测试语言效应在西方和非西方国家之间是否存在系统性差异。研究4进行预先指定的案例比较，以检验殖民历史与当代语言效应之间的关联。

## 共同框架与数据（研究1-4）

**文化地图与真实值。** 我们采用Inglehart-Welzel文化地图，这是一个由生存vs自我表达价值观（PC1）和传统vs世俗理性价值观（PC2）定义的二维价值空间。66个国家的真实文化坐标来自综合价值观调查（IVS），整合了世界价值观调查第7波（2017-2022）和欧洲价值观研究数据。IVS数据集涵盖109个国家，代表约90%的世界人口；我们的66国子集代表约62%的世界人口。我们使用在两个维度上具有强载荷的十个调查项目：幸福感（A008）、人际信任（A165）、对权威的尊重（E018）、政治行动（E025）、上帝的重要性（F063）、对同性恋（F118）和堕胎（F120）的态度、民族自豪感（G006）、后物质主义（Y002）和自主性（Y003）。

**模型。** 我们评估了23个大型语言模型（SI附录，表S1），分别由美国（n=13）、中国（n=8）和欧洲（n=2）开发，涵盖小型（<10B参数，n=7）和大型（≥10B参数，n=16）类别。模型通过API端点访问，时间为2025年2月至12月，使用温度=0.1。

**投影到文化空间。** 所有模型回应使用在IVS真实数据上训练的概率主成分分析（PPCA）投影到Inglehart-Welzel空间，然后应用于模型回应而不重新拟合。文化一致性量化为模型衍生坐标与IVS坐标之间的欧几里得距离；距离越小表示表征越准确。

## 研究1. 大型语言模型的内在价值取向

**研究问题。** 在未提供文化背景时，LLMs表达何种价值取向，这些坐标与IVS基准相比如何？

**设计。** 我们通过在不分配任何国家或文化身份的情况下呈现十个调查问题来评估LLMs的默认价值取向。模型接收一个系统提示，指示它们作为仅输出数字答案的调查响应系统，并有严格的格式要求以确保可解析的响应。提示中不提及任何国家、国籍或文化背景。

为了检验基线价值表达中的语言依赖性，问卷以六种联合国官方语言呈现：阿拉伯语（ar）、简体中文（zh-cn）、英语（en）、法语（fr）、俄语（ru）和西班牙语（es）。23个模型中的每一个都在所有六种语言中进行评估，产生138个模型-语言组合。

每个模型-语言组合的问卷呈现五次。使用重复中的众数回应作为最终答案。对于列表型问题（自主性），回应在众数计算前通过排序进行标准化。所有输出都根据严格的格式要求进行验证；包含解释性文本或无效值的回应被拒绝并重新发出最多三次。遵循IVS标准，仅当模型-语言组合对十个项目中的至少六个提供有效答案时才保留。

**分析。** 回应被投影到Inglehart-Welzel价值空间。对于后物质主义（Y002），回应按照IVS编码规则转换为三级分数（0=物质主义者，1=混合型，2=后物质主义者）。对于自主性（Y003），选定的特质被聚合为传统-世俗指数。PPCA提取两个主成分；Varimax旋转增强可解释性。我们将此PPCA映射视为固定的，以确保模型衍生坐标在与IVS基准相同的参考框架中表达。成分分数线性重新缩放以与IVS坐标对齐。

我们通过三项互补分析总结内在坐标和语言效应：

1. **与人类价值观的描述性比较。** 我们计算所有138个模型-语言组合的LLM平均坐标，并将其与IVS国家坐标（n=66）的均值和分布进行描述性比较。我们报告LLM价值观相对于人类群体是否倾向于世俗理性和自我表达象限。

2. **语言特定效应。** 我们进行单因素方差分析以测试平均PC1和PC2坐标在六种联合国语言间是否存在显著差异，随后进行Tukey HSD事后成对比较（详见SI附录）。

3. **模型跨语言稳定性。** 对于每个模型，我们计算六种语言间PC1和PC2坐标的范围（最大−最小）和标准差作为跨语言稳定性的度量。

**主要结果指标。** 每个模型-语言组合的投影坐标（PC1, PC2）。

## 研究2. 文化表征中的语言依赖性差异

**研究问题。** 提示语言是否影响文化表征准确度？

**设计。** 我们通过指示模型扮演66个国家的典型公民来评估文化表征。模型接收一个系统提示，将任务框定为文化价值观调查，并指示它们从在目标国家长大并分享其共同文化价值观的人的视角回答。提示明确说明："您正在扮演来自[国家]的典型公民。从在[国家]长大并分享该社会共同文化价值观的人的视角回答所有问题。"（SI附录提供所有13种语言的完整提示。）

66个国家在确保IVS参考数据可用性的同时最大化地理和文化多样性。国家按照既定分类被分为八个文化区域（区域成员详见SI附录）：新教欧洲、天主教欧洲、英语国家、东正教欧洲、拉丁美洲、非洲-伊斯兰、儒家文化圈和西亚南亚。

对于非英语国家（n=45），调查以英语和国家官方语言呈现，实现国家内语言比较。对于英语为主要官方语言的英语国家（n=21），调查仅以英语呈现。仅当同时具有英语和非英语官方语言数据时，国家才纳入语言对比分析；仅有英语作为评估语言的国家构成单独的纯英语组。评估的13种语言列于SI附录。多语言国家对每种官方语言分别评估（例如，瑞士：德语、法语、意大利语）。

由于低格式遵从度（重试下的高无效回应率），两个小型模型（Llama-3.2-3B和Qwen-2.5-3B）被排除，这也导致相对于IVS基准的极端距离。我们保留了21个模型。每个模型-国家-语言组合查询五次；使用众数回应。回应验证和投影程序遵循研究1。

**分析。** 对于每个非英语国家，我们为21个模型中的每一个计算模型层面的英语优势：

ΔD<sub>m</sub> = D<sub>m,native</sub> − D<sub>m,English</sub>

其中D<sub>m,native</sub>和D<sub>m,English</sub>是模型m在官方语言和英语提示下衍生坐标与IVS坐标之间的欧几里得距离。然后计算国家层面的英语优势为：

英语优势（%）= 100 × mean(ΔD<sub>m</sub>) / mean(D<sub>m,native</sub>)

正值表示英语下一致性更好；负值表示官方语言下一致性更好。

我们通过四项互补分析量化语言效应：

1. **按国家配对t检验。** 对于每个国家，我们使用模型层面ΔD<sub>m</sub>的单样本t检验测试21个模型的ΔD<sub>m</sub>是否显著不同于零。

2. **一致性分析。** 我们计算每个国家显示英语优势（ΔD<sub>m</sub> > 0）的模型比例，作为跨模型一致性的描述性度量。

3. **效应量量化。** 我们报告每个国家的配对Cohen's d = mean(ΔD<sub>m</sub>) / SD(ΔD<sub>m</sub>)。

4. **区域聚合。** 我们在八个区域内聚合英语优势，并使用单样本t检验测试区域均值是否与零不同。

**主要结果指标。**
- 文化距离：D = 模型衍生坐标与IVS坐标之间的欧几里得距离
- 英语优势：ΔD (%) = 100 × (D<sub>native</sub> − D<sub>English</sub>) / D<sub>native</sub>

统计检验和效应量详见SI附录。

## 研究3. 非西方文化表征中的数字东方主义

**研究问题。** 语言效应（英语vs官方语言）在西方和非西方国家之间是否存在系统性差异？

**设计。** 我们检验研究2中识别的英语优势在西方和非西方国家之间是否系统性变化。国家基于预先指定的区域标签（SI附录）分为两个主要组（西方，n=29；非西方，n=37）。西方国家包括新教欧洲、天主教欧洲和英语国家区域。非西方国家跨越非洲-伊斯兰、东正教欧洲、儒家文化圈、拉丁美洲和西亚南亚区域。完整的区域成员和国家列表详见SI附录。

我们进一步按文化区域对非西方国家进行分层，以测试东方主义效应的异质性并识别哪些区域显示最强的不对称性。

**分析。** 我们通过四组分析表征数字东方主义模式：

1. **西方vs非西方二元比较。** 我们使用独立样本t检验比较西方和非西方国家的平均英语优势。使用Cohen's d报告效应量。

2. **区域分层。** 我们计算八个文化区域（新教欧洲、天主教欧洲、英语国家、东正教欧洲、拉丁美洲、非洲-伊斯兰、儒家文化圈、西亚南亚）内的平均英语优势，并使用单样本t检验测试每个区域的均值是否显著不同于零。这识别哪些特定区域驱动整体东方主义效应并揭示区域异质性。我们报告每个区域的均值、标准误、95%置信区间和显著性水平。

3. **距离-优势耦合分析。** 我们检验英语优势的大小是否与国家与西方参考点的文化距离系统性相关。与西方的文化距离操作化为Inglehart-Welzel空间中每个国家的IVS坐标与英语国家的平均IVS坐标之间的欧几里得距离。我们计算与西方的文化距离与英语优势之间的Pearson相关（假设线性关系）和Spearman相关（对非线性单调关系稳健）。

4. **模型来源效应。** 我们通过比较美国开发、中国开发和欧洲开发模型的英语优势来测试模型来源是否影响东方主义效应的大小。对于每个文化区域，我们比较模型来源组之间的平均英语优势。

**主要结果指标。** 按文化区域和模型来源聚合的英语优势（ΔD）。统计比较和相关性详见SI附录。

## 研究4. 殖民历史与当代语言效应（探索性）

**研究问题。** LLM价值表征中的当代语言效应是否与历史殖民关系相关？

**设计。** 我们进行预先指定的案例比较，以检验殖民历史与当代语言效应之间的关联。案例选择旨在最小化地理和制度背景的明显差异，同时改变殖民语言暴露。

*实验4a：香港vs澳门比较。* 香港和澳门都是中国的特别行政区，具有相似的政治地位、经济发展水平（均为高收入）、地理接近性（均在珠江三角洲）和民族构成（均以华人为主）。然而，它们在殖民历史上差异显著：香港曾受英国统治（1842-1997），而澳门曾受葡萄牙统治（1557-1999）。我们比较香港的英语优势与澳门的葡萄牙语优势，后者类似地计算为：

葡萄牙语优势（%）= 100 × (Distance<sub>Chinese</sub> − Distance<sub>Portuguese</sub>) / Distance<sub>Chinese</sub>

其中Distance<sub>Chinese</sub>和Distance<sub>Portuguese</sub>是所有21个模型在中文（zh-cn）和葡萄牙语（pt）提示下的平均欧几里得距离。该比较在保持地理、文化和发展不变的同时改变殖民语言。

*实验4b：拉丁美洲语言变体。* 在拉丁美洲内部，我们比较具有不同殖民语言的国家的英语优势：西班牙语国家（n=11：阿根廷、玻利维亚、智利、哥伦比亚、厄瓜多尔、危地马拉、墨西哥、尼加拉瓜、秘鲁、乌拉圭、委内瑞拉）、葡萄牙语的巴西（n=1）和法语的海地（n=1）。所有三组共享地理区域（美洲）但在殖民语言上不同。我们测试英语优势是否在这些组间系统性变化。

*实验4c：非洲国家表征中的系统性偏差。* 对于仅有英语数据的非洲国家（n=11：肯尼亚、尼日利亚、加纳、南非、津巴布韦、赞比亚、坦桑尼亚、乌干达、博茨瓦纳、纳米比亚、马拉维），我们检验LLM在英语提示下的表征相对于IVS真实值是否显示系统性方向偏差。我们分别计算PC1（生存vs自我表达）和PC2（传统vs世俗理性）的平均坐标差异（模型衍生坐标减去IVS坐标），跨所有21个模型。正值表示系统性偏向自我表达（PC1）或世俗理性（PC2）价值观；负值表示偏向生存或传统价值观。我们使用单样本t检验测试这些偏差是否显著不同于零。

**分析。** 对于实验4a和4b，我们使用适当的统计检验比较组间的英语优势（或殖民语言优势）。对于实验4a，我们使用带Welch校正的独立样本t检验比较香港的英语优势与澳门的葡萄牙语优势（每个区域n=20个模型；除了从所有角色扮演研究中排除的两个低质量模型外，还有一个额外模型缺乏葡萄牙语或繁体中文支持）。对于实验4b，我们使用单因素方差分析比较西班牙语、葡萄牙语和法语拉丁美洲国家的平均英语优势。对于实验4c，我们使用单样本t检验测试平均坐标差异（PC1和PC2）是否显著不同于零，并报告Cohen's d作为偏差大小的度量。

**主要结果指标。** 
- 实验4a-4b：殖民语言优势：ΔD<sub>colonial</sub> (%) = 100 × (D<sub>Chinese</sub> − D<sub>colonial</sub>) / D<sub>Chinese</sub>，用于香港（英语）和澳门（葡萄牙语）
- 实验4c：平均坐标偏差：Δ<sub>PC1</sub> = mean(PC1<sub>model</sub> − PC1<sub>IVS</sub>) 和 Δ<sub>PC2</sub> = mean(PC2<sub>model</sub> − PC2<sub>IVS</sub>)，跨非洲国家

## 统计报告与稳健性

除非另有说明，所有统计检验使用双尾检验，α=0.05。效应量使用Cohen's d报告组间比较（d=[M₁−M₂]/SD<sub>pooled</sub>）和配对Cohen's d报告组内比较（d=M<sub>diff</sub>/SD<sub>diff</sub>）。对于分析集内的多重比较，我们报告未校正的p值，并注明结果何时通过Bonferroni校正（α<sub>corrected</sub>=0.05/n<sub>comparisons</sub>）。

**稳健性检验。** 关键发现经过稳健性测试：

1. **模型质量过滤。** 由于低格式遵从度（重试下的高无效回应率），两个小型模型（Llama-3.2-3B和Qwen-2.5-3B）从研究2-4中排除，这也导致相对于IVS基准的极端距离。所有报告的结果使用过滤后的21个模型集。

2. **仅大型模型。** 我们对≥10B参数的模型（n=16）重复分析，以测试发现是否由可能具有较低文化知识的小型模型驱动（详见SI附录）。

3. **模型来源一致性。** 我们评估数字东方主义模式是否在不同地区开发的模型（美国、中国、欧洲）中成立。按模型来源的结果报告于SI附录。

**数据可用性。** 所有模型回应、IVS参考数据、分析代码和补充材料可在[存储库URL]获取。该研究按照AI研究的机构指南进行；未涉及人类受试者。所有数据收集均符合相应API提供商的服务条款。
