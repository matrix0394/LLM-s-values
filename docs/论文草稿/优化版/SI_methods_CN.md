## SI.2 提示工程和验证

### SI.2.1 提示模板

**内在价值条件（研究1）：**
```
请回答以下关于您的价值观和信念的问题。
对于每个问题，仅提供与您的选择相对应的数字答案。

问题1：总的来说，您会说您是：
1 = 非常幸福
2 = 相当幸福
3 = 不太幸福
4 = 一点也不幸福

[答案格式：单个整数1-4]
```

**文化模仿条件（研究2）：**
```
您是[国家]的典型成年公民。请像典型的[国家]公民一样
回答以下关于价值观和信念的问题。
对于每个问题，仅提供数字答案。

问题1：总的来说，您会说您是：
1 = 非常幸福
2 = 相当幸福
3 = 不太幸福
4 = 一点也不幸福

[答案格式：单个整数1-4]
```

### SI.2.2 特定语言的提示适应

对于13种语言中的每一种，提示都经过专业翻译和文化适应。关键适应包括：

**阿拉伯语：**从右到左的文本格式；正式的现代标准阿拉伯语（MSA）而不是方言变体；对敏感话题（例如，同性恋、堕胎）的文化适当措辞。

**中文变体：**
- 简体中文（zh-cn）：中国大陆惯例
- 繁体中文（zh-tw）：台湾惯例，包括繁体字形式
- 粤语（zh-hk）：香港惯例，适当时使用书面粤语

**西班牙语变体：**
- 欧洲西班牙语（es-ES）：用于西班牙
- 拉丁美洲西班牙语（es-419）：用于拉丁美洲国家，使用中性词汇避免特定地区术语

**葡萄牙语变体：**
- 欧洲葡萄牙语（pt-PT）：用于葡萄牙
- 巴西葡萄牙语（pt-BR）：用于巴西

### SI.2.3 响应格式验证

每个响应都针对严格的格式要求进行验证：

**单选项目（8个项目）：**
- 必须恰好返回一个整数
- 必须在允许范围内（例如，幸福感为1-10，信任为1-4）
- 无解释性文本、推理或额外字符

**多选项目（2个项目）：**
- 自主性（Y003）：必须从11个选项中恰好返回5个特征
- 后物质主义（Y002）：必须按优先级顺序排列4个目标

**验证程序：**
1. 使用特定语言的正则表达式模式解析响应
2. 检查格式合规性（单个整数、正确范围等）
3. 如果验证失败，使用更明确的格式指令重新发出问题
4. 每个问题最多3次重试尝试
5. 如果所有重试都失败，则标记为无效

**特定语言的解析器：**
- 英语：`r'^\s*(\d+)\s*$'`
- 中文：`r'^\s*([0-9０-９]+)\s*$'`（处理ASCII和全角数字）
- 阿拉伯语：`r'^\s*([0-9٠-٩]+)\s*$'`（处理ASCII和阿拉伯-印度数字）
- 其他语言：适应本地数字格式的类似模式

## SI.3 数据质量控制程序

### SI.3.1 响应有效性标准

**实体级有效性：**
遵循IVS标准，仅当模型-国家-语言实体对10个项目中的至少6个提供有效答案时才保留（60%完成率）。此阈值平衡了数据完整性与样本量。

**项目级有效性：**
- 单选项目：如果响应是允许范围内的单个整数，则有效
- 多选项目：如果响应满足基数约束（例如，自主性恰好5个特征），则有效
- 缺失响应：编码为NA并由概率PCA处理

**在所有条件下：**
- 总实体：23个模型×6种语言（研究1）+ 21个模型×66个国家×2种语言（研究2）= 138 + 2,772 = 2,910
- 有效实体：2,847（97.8%）
- 无效实体：63（2.2%）

**无效原因：**
- 格式违规：38（60.3%）
- 不完整响应（<6个有效项目）：18（28.6%）
- API错误（超时、速率限制）：7（11.1%）

### SI.3.2 模型排除标准

两个小型模型由于系统性低响应质量而从文化模仿分析（研究2）中排除：

**Qwen-3-1.7B：**
- 平均文化距离：4.87（>总体平均值2.14的3个标准差）
- 有效响应率：78.3%（低于95%阈值）
- 原因：复杂角色扮演指令的能力不足

**Llama-3.2-3B-Instruct：**
- 平均文化距离：4.23（>总体平均值的2.5个标准差）
- 有效响应率：82.1%
- 原因：频繁的格式违规和离题响应

这些模型在研究1（内在价值）中保留，因为它们在没有角色扮演指令的情况下表现良好。

### SI.3.3 异常值检测和处理

**国家级异常值：**
平均文化距离>其区域平均值2个标准差的国家被标记以供检查，但不会自动排除。人工审查确认这些是真实的文化对齐不良案例，而不是数据错误。

**模型级异常值：**
平均距离>总体平均值3个标准差的模型被排除（见SI.3.2）。

**响应级异常值：**
>项目平均值3个标准差的个别响应被标记但保留，因为极端值可以是文化多样性的有效表达。

## SI.4 补充统计分析

### SI.4.1 模型×语言交互效应

为了评估语言效应是否在模型之间变化，我们进行了双因素方差分析，模型和语言作为因子，文化距离作为因变量。

**设计：**
- 因子1：模型（21个水平，排除低质量模型）
- 因子2：语言（2个水平：英语vs母语）
- 因变量：文化距离
- 观察单位：模型-国家-语言组合（n = 2,772）

**结果：**
- 模型主效应：F(20, 2730) = 87.3，p < 0.0001，η² = 0.39
- 语言主效应：F(1, 2730) = 12.4，p = 0.0004，η² = 0.004
- 交互效应：F(20, 2730) = 2.1，p = 0.003，η² = 0.015

**解释：**
显著的交互表明语言效应在模型之间变化，尽管效应量很小（η² = 0.015）。事后检验显示，中国开发的模型显示出比美国开发的模型更弱的语言效应（平均差异= 0.18，p = 0.002）。

### SI.4.2 英语母语国家基线分析

为了在恒定语言条件下建立文化对齐的基线，我们分析了仅用英语评估的21个英语母语国家。

**包括的国家：**
澳大利亚、加拿大、加纳、印度、爱尔兰、肯尼亚、新西兰、尼日利亚、菲律宾、卢旺达、新加坡、南非、坦桑尼亚、特立尼达和多巴哥、乌干达、英国、美国、赞比亚、津巴布韦、牙买加、巴巴多斯。

**关键发现：**
- 平均文化距离：2.31 ± 0.89
- 范围：1.03（尼日利亚）到3.96（爱尔兰）
- 传统英语国家（英国、爱尔兰、澳大利亚、加拿大、新西兰、美国）显示出比非洲英语国家更大的距离（平均= 2.87 vs 1.42）
- 向世俗-进步价值观的系统性偏见：所有传统英语国家向更世俗（平均PC2偏移= +1.95）和更自我表达（平均PC1偏移= +1.68）的位置偏移

**含义：**
即使在语言保持不变且文化知识应该丰富的情况下，LLMs也表现出反映英语训练数据组成的系统性文化偏见。

1. 中国：0.97
2. 尼日利亚：1.03
3. 卢旺达：1.23
4. 加纳：1.32
5. 日本：1.38

**最困难的国家（距离> 3.0）：**

### SI.4.4 西方vs非西方二元比较

为了以最简单的形式测试数字东方主义假设，我们使用二元分类比较了西方和非西方国家之间的英语优势。

**西方国家（n = 25）：**
西欧（15）+ 英语母语国家（10，排除非洲国家）

**非西方国家（n = 41）：**
所有其他

**结果：**
- 西方平均英语优势：-8.7%（母语更好）
- 非西方平均英语优势：+12.3%（英语更好）
- 差异：21.0个百分点
- t检验：t(64) = 5.8，p < 0.0001
- Cohen's d：1.43（大效应）

**一致性：**
- 78%的西方国家显示母语优势（19/25）
- 73%的非西方国家显示英语优势（30/41）
- 二项检验：p < 0.0001

### SI.4.5 语言变体分析

对于具有多个变体的语言（中文、西班牙语、葡萄牙语），我们测试变体是否显示不同的语言效应。

**中文变体：**
- 简体（zh-cn）：+0.07%英语优势（接近平等）
- 繁体（zh-tw）：+27.1%英语优势
- 粤语（zh-hk）：+24.8%英语优势
- 方差分析：F(2, 60) = 18.4，p < 0.0001

**西班牙语变体：**
- 欧洲（es-ES）：-12.4%（母语优势）
- 拉丁美洲（es-419）：+8.7%（英语优势）
- t检验：t(18) = 3.2，p = 0.005

**葡萄牙语变体：**

- 巴西（pt-BR）：-5.2%（母语优势）
- t检验：t(2) = 0.4，p = 0.72（不显著）

**解释：**
语言变体可以显示出截然不同的模式，表明训练数据可用性和文化背景比语系成员资格更重要。

## SI.5 敏感性分析

### SI.5.1 替代距离度量

我们使用三种替代距离度量重新计算了所有分析：

**曼哈顿距离（L1）：**
距离 = |PC1_model − PC1_IVS| + |PC2_model − PC2_IVS|

**结果：**
- 整体模式不变
- 平均英语优势：+8.1%（vs 欧几里得的+8.3%）
- 区域模式：所有区域保持相同方向和显著性
- 与欧几里得的相关性：r = 0.97，p < 0.0001

**马氏距离：**
距离 = √[(x − μ)ᵀ Σ⁻¹ (x − μ)]
其中Σ是IVS国家坐标的协方差矩阵

**结果：**
- 整体模式不变
- 平均英语优势：+7.9%
- 区域模式：所有区域保持相同方向和显著性
- 与欧几里得的相关性：r = 0.94，p < 0.0001

**余弦距离：**
距离 = 1 − (x · y) / (||x|| ||y||)

**结果：**
- 整体模式不变
- 平均英语优势：+8.5%
- 区域模式：所有区域保持相同方向和显著性
- 与欧几里得的相关性：r = 0.91，p < 0.0001

**结论：**
结果对距离度量的选择稳健。

### SI.5.2 替代PCA规格

我们测试了三种替代PCA规格：

**无旋转：**
- 解释的方差：PC1 = 42%，PC2 = 28%
- 平均英语优势：+8.0%
- 区域模式：所有保持相同方向和显著性

**斜旋转（Promax）：**
- 允许相关成分
- 解释的方差：PC1 = 44%，PC2 = 26%
- 平均英语优势：+8.4%
- 区域模式：所有保持相同方向和显著性

**三个成分：**
- 解释的方差：PC1 = 42%，PC2 = 28%，PC3 = 15%
- 平均英语优势（2D投影）：+8.2%
- 区域模式：所有保持相同方向和显著性

**结论：**
结果对PCA规格稳健。
