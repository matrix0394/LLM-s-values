# 讨论（中文版 - v4.0）

**目标长度：约2200字**

## 1. 解开基线语言效应和文化知识效应

我们的结果识别了LLM文化表征中语言依赖的两个不同层次。首先，在没有任何文化角色扮演的情况下，提示语言本身系统性地塑造表达的价值观。当模型在没有分配文化身份的情况下被查询时，英语提示引发更世俗的价值概况，而阿拉伯语提示引发更传统的价值概况，在传统-世俗维度上产生1.71个单位的差异。这种基线语言效应是维度特定的，不延伸到生存-自我表达轴。

这一发现对解释文化角色扮演中的语言效应具有重要意义。原则上，观察到的非西方文化的英语优势可能反映（a）将模型响应移向西方训练默认值的基线语言偏移，或（b）跨语言文化知识的可用性和结构差异。区分这些可能性对于解释跨语言文化对齐至关重要。

我们结果的几个特征表明，仅基线语言效应不能解释观察到的不对称性。首先，在共享语系内出现显著的异质性。例如，共享书面中文的中国和台湾分别表现出接近零和非常大的英语优势。同样，香港和澳门——都是中国的特别行政区——显示出相反的语言效应。这种对比难以仅用基线语言属性来调和，而是指向文化信息如何在语言和数字背景中被表征的差异。

其次，即使在语言保持不变的情况下，系统性的文化偏差仍然存在。当英语国家仅用英语评估时，传统英语社会如爱尔兰、澳大利亚和加拿大表现出比几个非洲英语国家更大的文化距离。这种模式表明，文化不对齐可以独立于语言切换而产生，表明可用文化信息的结构在基线语言效应之外发挥作用。

第三，模型来源的差异进一步支持这一解释。在中国开发的模型对汉藏语系和闪米特语系背景表现出比在美国开发的模型更弱的英语优势。如果基线语言效应是主要驱动因素，那么模型来源的这种差异将是意外的。相反，这些模式与模型之间训练数据组成的变化一致。

综合来看，这些发现表明数字东方主义反映了跨语言文化知识分布的差异，而基线语言效应可能调节——但不能完全解释——观察到的不对称性的幅度。

## 2. 解释数字东方主义：训练数据作为合理机制

在这里，我们使用术语*数字东方主义*作为系统性模式的描述性标签，其中非西方文化在英语提示下更准确地被表征，而西方文化倾向于在其母语中更好地被表征。这种用法不是为了暗示故意偏见或直接的历史连续性，而是为了捕捉多语言文化表征中的实证不对称性。效应量很大（Cohen's d = 1.43）且高度一致，21个模型中的19个（90%）对伊斯兰国家显示相同的方向模式。

对这种模式的一个合理解释是，LLMs不成比例地通过英语来源了解非西方社会，包括学术写作、新闻报道和在线讨论。相比之下，西欧社会有着广泛的母语文化生产的悠久传统，这些传统在数字语料库中得到了很好的体现。虽然我们没有直接测量训练数据组成，但观察到的语言依赖准确性模式与跨语言文化信息的可用性和多样性差异一致。

东亚提供了这种异质性的特别清晰的例证。中国表现出近乎完美的语言平等（+0.07%）和所有国家中最低的平均文化距离（0.97），这与大型且自我维持的中文数字生态系统的存在一致。日本和韩国同样显示出最小的英语优势（+3.3%和+3.0%），这可能反映了大量母语内容和全球观众产生的广泛英语文化话语的结合。相比之下，台湾和香港显示出观察到的最强英语优势之一（+27.1%和+24.8%），这与相对于广泛的英语覆盖范围更有限的母语数字表征一致。

拉丁美洲出现了类似的模式。巴西表现出母语优势（-5.2%），这与其葡萄牙语互联网生态系统的规模一致，而较小的西班牙语国家和海地显示出显著的英语优势（海地+20.4%）。这些对比表明，仅语系不能决定文化对齐；相反，数字内容生产的规模和背景似乎很重要。

## 3. 西欧和母语文化表征

西欧国家显示出与大多数非西方地区相反的模式，78%在母语提示下表现出更高的文化对齐（总体效应：-11.5%，p = 0.03）。瑞士（-33.5%）、德国（-26.1%）和意大利（-24.5%）等国家显示出特别强的母语优势。这种模式与广泛的母语档案的存在一致，这些档案捕捉了文化自我表征的悠久传统——德国哲学传统、法国文学文化、意大利艺术话语——编码了在英语摘要或翻译中不太完全保留的文化细微差别和内部多样性。

同时，对西方社会的英语评估揭示了系统性偏见。传统英语国家相对于IVS基准一致地向更世俗（PC2上+1.95个单位）和更自我表达（PC1上+1.68个单位）的位置偏移。爱尔兰提供了一个说明性例子：尽管其基于调查的文化位置适度传统（PC2 = -0.68），模型表征将其置于高度世俗的社会之中（PC2 = +1.85），偏移2.52个单位。这种模式可能反映了英语数字话语中的选择效应，其中不成比例地放大了自由和进步的观点。

这些发现建立了一个重要的基线：即使在文化知识应该丰富的背景下，LLM表征也受到数字训练数据中存在的声音分布的塑造。

## 4. 文化软实力和语言平等

日本（+3.3%）和韩国（+3.0%）代表了非西方社会英语优势一般模式的显著例外。尽管地理和文化上远离西欧，两者都表现出接近语言平等。

一个合理的解释是文化软实力。动漫、电影、音乐和电视等文化出口产生了由与这些文化密切接触的创作者和观众产生的广泛英语话语。这种内容可能以不同于外部报道或学术分析的方式传达文化知识。相比之下，尽管国际知名度高，台湾（+27.1%）和香港（+24.8%）等地区更多地通过政治或经济框架而不是通过文化生产在英语中被讨论。

中国（+0.07%）和巴西（-5.2%）说明了实现平等的不同途径：规模。大型母语数字生态系统产生足够的训练数据以支持文化准确表征，而不依赖英语调解。这些案例表明，文化影响和数据丰富性都可以缓解数字东方主义，尽管通过不同的机制。

## 5. 模型来源和部分缓解

跨模型来源的比较表明，训练多样性可以部分缓解语言不对称性。中国开发的模型对汉藏语系表现出较弱的英语优势（+1.9% vs 美国模型的+16.8%，p < 0.01）和闪米特语系（+8.2% vs +19.6%，p < 0.05）。欧洲模型对斯拉夫语系显示出更强的母语优势（-43.3%），可能反映了地理接近性和训练数据重点。

然而，没有模型来源完全消除数字东方主义。中国模型对阿拉伯国家仍然显示出英语优势（+8.2%），美国模型对日耳曼语系显示出母语优势（-15.7%）。这一发现表明，区域专业化提供了部分缓解，但没有解决多语言文化知识中更广泛的不平衡。真正公平的AI生态系统需要（a）所有模型中的全球多样化训练数据，或（b）用户可以根据其文化背景选择的区域专业化模型组合。

## 6. 实践意义

我们的发现强调了多语言AI系统开发和部署的重要意义。

**对于AI开发者**，最紧迫的优先事项是多样化训练数据，以包括来自代表不足地区的高质量母语内容。我们的结果表明，训练数据组成而不是模型架构驱动文化偏见。中国模型对中文内容的较弱偏见（+1.9% vs 美国模型的+16.8%）表明多样化是有效的。具体策略包括：

- 与代表不足地区的母语内容创作者和平台合作
- 优先考虑质量而不是数量：巴西的葡萄牙语优势（-5.2%）表明，大型、高质量的母语生态系统可以克服英语主导地位
- 解决语言变体：欧洲西班牙语/葡萄牙语训练数据不能转移到拉丁美洲变体
- 利用文化软实力：日本和韩国的最小英语优势（+3%）表明文化出口产生真实的英语知识

**对于用户**，我们的发现挑战了母语互动总是产生更准确文化表征的直觉假设。特定地区指导：
- **西欧**：使用母语（德语、法语、意大利语等）
- **东亚**：中文对中国效果很好（+0.07%），但英语可能对台湾（+27.1%）和香港（+24.8%）更好
- **拉丁美洲**：葡萄牙语对巴西有效（-5.2%），但英语可能对较小的西班牙语国家和海地（+20.4%）更好
- **伊斯兰世界**：英语目前提供更好的准确性（+17.4%），尽管这反映了训练数据差距而不是固有的优越性
- **东欧**：结果混合；针对特定国家测试母语和英语

**对于政策制定者**，这些结果强调了需要解决文化表征和语言公平的AI治理框架：
- 多语言训练数据组成和透明度标准
- 部署前跨语言文化能力评估要求
- 支持代表不足地区的母语数字内容创作
- 区域AI开发激励措施（中国、欧洲、拉丁美洲、非洲模型）

如果底层训练数据仍然不平衡，仅将界面翻译成当地语言不足以确保文化准确的表征。改善文化表征可能需要扩大母语数据来源和多样化主导语言中表征的观点。

## 7. 检测殖民历史效应的挑战

研究4的探索性分析揭示了检测当代AI系统中历史殖民影响的重大挑战。尽管有理论动机的自然实验比较香港vs澳门和具有不同殖民语言的拉丁美洲国家，我们没有发现语言效应的显著差异。

几个因素可能解释这些零发现。首先，**跨模型的高方差**（在某些情况下SD超过170%）表明，个别模型以高度特异性的方式编码文化知识，可能反映训练数据组成、策展实践和模型架构的差异。这种异质性可能掩盖了在训练数据层面存在但未在模型间一致反映的系统性模式。与研究3的稳健东方主义发现的对比——显示跨模型的一致模式——表明殖民历史效应（如果存在）比更广泛的东西方不对称性更微妙和可变。

其次，**殖民历史效应可能由我们无法控制的当代因素中介**，如当前英语使用模式、互联网内容分布和与英语国家的经济整合。例如，香港的英语优势可能不仅反映历史英国统治，还反映其作为国际金融中心的当前地位和高当代英语使用。没有这些中介变量的数据，我们无法区分直接殖民遗产效应和由当前语言和经济实践解释的效应。纳入GDP、互联网普及率和英语熟练度指数（例如EF EPI）控制变量的未来研究可能更好地分离历史殖民影响。

第三，**我们在实验4c中遇到的数据限制**——英国殖民的非洲国家缺乏母语评估——突显了多语言AI评估中的系统性差距。由于殖民历史而将英语作为官方语言的国家（肯尼亚、尼日利亚、加纳、南非、津巴布韦、赞比亚）通常仅用英语评估，为评估母语表征创造了盲点。这反映了多语言AI研究中更广泛的挑战，其中评估数据集中的语言可用性本身受历史权力动态的塑造。我们数据集中缺乏斯瓦希里语、约鲁巴语、阿坎语、祖鲁语、绍纳语和本巴语评估——尽管这些是数亿人使用的语言——说明了殖民遗产如何继续构建AI开发和评估中优先考虑哪些语言。

第四，**统计功效限制**由于小样本量（特别是葡萄牙语和法语拉丁美洲国家，各n=1）阻止了检测潜在有意义差异。实验4b中的大效应量（η²=0.171）尽管不显著（p=0.391）表明殖民语言差异可能存在，但需要更大的样本才能可靠检测。

这些发现强调了通过当代AI系统追踪历史影响的复杂性，并突显了以下需求：(1) **更大的模型样本**以克服高方差并增加统计功效，(2) **控制变量**用于当代语言、经济和技术因素以分离历史效应，(3) **更全面的多语言评估数据集**包括以前殖民地区的母语，特别是AI研究中目前代表不足的非洲语言，(4) **替代方法**如训练数据分析以直接检查殖民历史如何在预训练语料库中编码。

研究3的稳健东方主义发现与研究4的零殖民历史结果之间的对比表明，虽然AI表征中的广泛东西方不对称性是可检测和一致的，但像殖民关系这样更具体的历史影响更难分离。这可能反映了东方主义通过多种强化机制（语言主导、经济权力、媒体表征）运作的事实，而殖民历史效应更局部化，可能被当代因素混淆。或者，这可能表明殖民遗产主要通过当代中介变量（当前英语使用、经济整合）而不是作为训练数据中的直接历史印记表现出来。

尽管有这些零发现，研究4通过以下方式做出了重要的方法学贡献：(1) 展示了检测AI系统中历史影响的挑战，(2) 识别了多语言评估中的系统性差距（以前殖民的非洲国家缺乏母语数据），(3) 确立了跨模型的高方差是检测微妙历史效应的关键障碍。这些见解为未来的研究设计提供信息，并突显了需要更全面的方法来研究历史权力动态如何塑造当代AI系统。

## 8. 局限性和未来方向

我们的研究有几个局限性。我们依赖基于调查的文化框架，这些框架可能无法捕捉所有文化显著维度，特别是在非西方背景下。Inglehart-Welzel二维框架可能错过重要的文化维度，如儒家价值观（等级、和谐、面子）、伊斯兰价值观（乌玛、清真/非清真）或非洲价值观（乌班图、集体主义）。我们将国家视为单一实体，尽管存在显著的内部多样性——爱尔兰的案例说明了这一点：LLMs将爱尔兰表征为高度世俗（PC2 = +1.85），这可能准确反映了主导互联网话语的年轻、城市、受过教育的爱尔兰声音，同时错过了年长、农村、传统的观点。

我们还从观察到的模式而不是直接测量推断与训练数据组成相关的机制。虽然我们的证据与训练数据解释一致（区域异质性、模型来源效应），但我们不能在没有实验干预的情况下明确证明因果关系。未来的工作应该进行因果实验，例如：
- 在具有不同语言组成的受控语料库上训练模型
- 在额外的母语文化内容上微调现有模型
- 消融研究删除特定类型的训练数据（例如，关于非西方文化的英语新闻）

时间动态呈现另一个局限性。世界价值观调查数据来自不同年份（2017-2022），文化价值观随时间演变。在最近互联网数据上训练的LLMs可能比历史WVS数据更好地反映当代价值观，反之亦然。我们无法确定LLM-WVS差异是否反映LLM偏见或真正的文化变化。

最后，我们的发现可能不会推广到文化价值问题之外的其他任务（翻译、摘要、问答）或其他提示策略（少样本学习、思维链推理）。未来的工作应该检查语言效应是否在不同任务和方法中持续存在。

尽管有这些局限性，观察到的模式在模型、区域和分析选择中的一致性——效应量为Cohen's d = 1.43，90%的模型具有方向一致性——表明语言依赖的文化不对称性是当前LLMs的基本特征，而不是方法论人工制品。解决这些偏见将需要致力于构建公平服务所有文化的AI系统的AI开发者、研究人员和政策制定者的持续努力。
