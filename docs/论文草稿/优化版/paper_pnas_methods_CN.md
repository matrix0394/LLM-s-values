# 材料与方法

## 概述

我们进行了四项研究来表征大型语言模型如何跨语言表达和表征文化价值观。研究1在没有文化角色扮演的情况下建立模型的内在价值概况。研究2评估模型在明确角色扮演指令下模仿国家特定文化价值观的能力。研究3开发了一个统一的评分管道，将模型输出映射到Inglehart-Welzel文化价值空间并量化文化对齐度。研究4分析文化模仿表现的语言效应、区域模式和稳健性。

## 共同框架和数据（研究1-4）

**文化地图和真实值。** 我们采用Inglehart-Welzel文化地图将模型表达的价值观和国家级文化概况定位在由生存与自我表达价值观（PC1）和传统与世俗理性价值观（PC2）定义的二维价值空间中。66个国家的真实文化坐标从综合价值观调查（IVS）获得，该调查整合了世界价值观调查第7波（2017-2022）和欧洲价值观研究数据，涵盖109个国家的超过40万个个人调查响应。

遵循既定实践，我们使用在两个维度上具有强负荷的十个调查项目：幸福感（A008）、人际信任（A165）、对权威的尊重（E018）、政治行动（E025）、上帝的重要性（F063）、对同性恋的态度（F118）和堕胎（F120）、民族自豪感（G006）、后物质主义（Y002）和自主性（Y003）。这些项目定义了一个固定的文化坐标系统；所有模型生成的响应都在这些项目上评分并投影到这个既定空间中。

**模型和查询设置。** 我们评估了23个大型语言模型（SI附录，表S1），在美国（n = 10）、中国（n = 8）和欧洲（n = 5）开发，跨越小型（<10B参数，n = 7）和大型（≥10B参数，n = 16）类别。模型包括GPT-4o、Claude-3.5-Sonnet、Gemini-2.0-Flash、DeepSeek-V3、Qwen-2.5-72B、Mistral-Large等，选择以最大化来源、架构和规模的多样性。模型通过API端点在2024年2月至12月之间访问，使用固定温度0.1以最小化随机变化。

在所有模型-语言-条件组合中，每个问卷进行五次。重复中的众数响应用作最终答案，以减少随机变化同时保留调查项目的序数结构。对于列表类型问题（例如，自主性特征），响应在众数计算之前通过排序进行标准化以确保顺序不变性。

**响应验证和质量控制。** 所有输出使用特定语言的解析器针对严格的格式要求进行验证。单选项目必须返回允许范围内的单个整数（例如，幸福感为1-10），多选项目必须满足预定义的基数约束（例如，自主性恰好五个特征）。包含解释性文本、推理轨迹或无效值的响应被拒绝。

如果响应验证失败，问题将重新发出最多三次，并逐步提供更明确的格式说明。所有重试都失败的响应标记为无效。遵循IVS标准，仅当模型-国家-语言实体对十个项目中的至少六个提供有效答案时才保留。在所有条件下，有效响应率超过95%。

某些模型需要额外处理：生成内部推理的模型（例如，o1系列）被指示抑制推理并仅返回数字答案；具有更高延迟的模型被分配扩展超时（每个问题最多60秒）。所有模型使用相同的温度设置（0.1）和系统级指令进行查询。

## 研究1. 大型语言模型的内在价值概况

**设计。** 在内在价值条件下，模型在没有被分配任何国家或文化身份的情况下回答十个调查问题。标准化提示格式为："请回答以下关于您的价值观和信念的问题。对于每个问题，仅提供与您的选择相对应的数字答案。"没有提及国家、国籍或文化背景。

为了检查基线价值表达中的语言依赖性，问卷在六种联合国官方语言中进行：阿拉伯语、中文（简体）、英语、法语、俄语和西班牙语。23个模型中的每一个都在所有六种语言中进行评估，产生138个模型-语言组合。

**结果。** 对于每个模型和语言，对十个项目的响应遵循IVS编码规则（见研究3）转换为项目分数并投影到Inglehart-Welzel价值空间中。结果坐标（PC1，PC2）代表给定提示语言下模型的内在价值概况。使用单因素方差分析评估语言对内在价值的影响，语言作为因子，模型作为观察单位。

## 研究2. 通过国家角色扮演进行文化模仿

**设计。** 在文化模仿条件下，模型被提示作为指定国家的典型成年公民回应。标准化系统提示格式为："您是[国家]的典型成年公民。请像典型的[国家]公民一样回答以下关于价值观和信念的问题。对于每个问题，仅提供数字答案。"（所有13种语言的完整提示见SI附录。）

包括66个国家，选择以最大化地理和文化多样性，同时确保IVS参考数据的可用性。国家按照既定分类分为八个文化区域：西欧（n = 15）、东欧（n = 10）、拉丁美洲（n = 11）、伊斯兰/阿拉伯（n = 8）、撒哈拉以南非洲（n = 7）、儒家（n = 5）、南亚（n = 5）和东正教/斯拉夫（n = 5）。

对于非英语母语国家（n = 66），调查在英语和国家官方语言中进行。语言根据官方语言地位和使用人口选择。评估了13种语言：阿拉伯语、中文（简体和繁体）、荷兰语、英语、法语、德语、意大利语、日语、韩语、葡萄牙语、俄语、西班牙语和土耳其语。多语言国家对每种主要官方语言分别评估（例如，加拿大：英语和法语；瑞士：德语、法语、意大利语；比利时：荷兰语和法语）。这种设计使得在保持国家身份和模型不变的情况下进行国家内提示语言比较成为可能。

对于英语母语国家（n = 21），调查仅在英语中进行，为恒定语言条件下的文化对齐提供基线。

所有23个模型都包括在研究1中。对于研究2，两个小型模型（Llama-3.2-3B和Qwen-2.5-3B）由于系统性低响应质量而被排除，定义为平均文化距离超过IVS参考分布的三个标准差，导致21个模型用于文化角色扮演分析。

**结果。** 对于每个保留的模型、国家和提示语言，响应投影到与IVS真实值相同的文化空间中（见研究3）。文化模仿表现通过模型衍生坐标与IVS国家坐标之间的距离量化。通过比较同一国家和模型内的英语和母语距离来评估语言效应。

## 研究3. 文化评分、投影和距离度量

**项目编码。** 验证的众数响应组装成响应矩阵，行代表模型-国家-语言实体，列代表十个调查项目。对于后物质主义项目（Y002），响应根据四个目标的优先级排名遵循标准IVS编码规则转换为三级物质主义分数（0 = 物质主义者，1 = 混合，2 = 后物质主义者）。对于自主性项目（Y003），受访者从十一个选项中选择五个特征；选定的特征通过对比传统指标（服从、宗教信仰）与世俗理性指标（独立、想象力、宽容）聚合为传统-世俗指数。

**投影到Inglehart-Welzel空间。** 使用概率主成分分析（PPCA）进行降维以适应缺失值。在IVS真实数据（66个国家×10个项目）上训练固定的PPCA模型，然后在不重新拟合的情况下应用于所有模型生成的响应，确保跨条件的共同坐标系统。提取两个主成分，分别解释42%和28%的方差。应用Varimax旋转以增强可解释性同时保持正交性。第一个旋转成分（PC1）对应于生存-自我表达维度；第二个（PC2）对应于传统-世俗维度。

模型衍生的成分分数使用基于回归的转换线性重新缩放以与IVS坐标对齐。具体来说，对于每个成分，我们使用两者都可用的观察子集拟合线性回归预测IVS国家分数从模型衍生分数，然后将拟合的转换应用于所有模型衍生分数。这确保模型坐标在规模和原点方面与IVS坐标直接可比。

**文化距离和语言优势。** 文化对齐量化为模型衍生坐标（PC1_model，PC2_model）与相应IVS国家坐标（PC1_IVS，PC2_IVS）之间的欧几里得距离：

距离 = √[(PC1_model − PC1_IVS)² + (PC2_model − PC2_IVS)²]

较小的距离表示更准确的文化表征。对于非英语母语国家，英语优势度量计算为在保持国家身份和模型不变的情况下，英语提示下的距离相对于母语提示下的距离的相对减少：

英语优势（%）= 100 × (距离_母语 − 距离_英语) / 距离_母语

正值表示英语提示下表现更好；负值表示母语提示下表现更好。

## 研究4. 文化模仿表现的统计分析

研究4分析研究2和3中观察到的文化模仿表现的模式、决定因素和稳健性。我们进行八组分析来表征语言效应、区域模式、语系模式、模型来源效应、模型质量效应、距离-优势耦合和稳健性。

**设计。** 所有分析使用研究3的文化距离数据作为主要结果。对于非英语母语国家，我们为每个模型-国家对计算英语优势度量：

英语优势（%）= 100 × (距离_母语 − 距离_英语) / 距离_母语

正值表示英语提示下表现更好；负值表示母语提示下表现更好。该度量使得能够直接比较具有不同基线距离的国家之间的语言效应。

**分析1：语言对内在价值表达的效应。** 在内在价值条件（研究1）中，使用单因素方差分析评估语言对表达价值的影响，提示语言（六个水平）作为因子，分别针对PC1（传统-世俗）和PC2（生存-自我表达），将每个模型视为观察单位（n = 23个模型×6种语言= 138个观察）。事后成对比较使用Tukey的HSD检验来识别哪些语言对显著不同。这一分析确定在没有文化角色扮演的情况下，提示语言本身是否系统性地改变表达的价值观。

**分析2：语言对文化模仿的效应和区域模式。** 在文化模仿条件（研究2）中，通过对比英语提示与母语提示下的模仿距离，在同一国家和模型内评估语言效应。对于每个非英语母语国家，我们使用跨21个模型的配对t检验来评估英语和母语之间的平均距离是否不同。我们使用上面定义的英语优势度量来量化幅度。

通过在八个文化区域（西欧、东欧、拉丁美洲、伊斯兰/阿拉伯、撒哈拉以南非洲、儒家、南亚、东正教/斯拉夫）内聚合国家级英语优势估计，并使用单样本t检验测试平均区域优势是否与零不同，获得区域摘要。区域比较使用双样本t检验来识别哪些区域显示显著不同的语言效应。这一分析测试语言效应是否在文化背景中系统性变化。

**分析3：语系分层。** 为了评估语言效应是否推广到单个语言之外，我们根据语言学分类按语系聚合国家：日耳曼语系（德语）、罗曼语系（西班牙语、法语、意大利语、葡萄牙语）、斯拉夫语系（俄语）、闪米特语系（阿拉伯语）、汉藏语系（简体中文、繁体中文、粤语）、日本语系（日语）和韩语系（韩语）。对于每个语系，我们计算母语属于该语系的所有模型-国家对的平均英语优势。配对t检验比较每个语系内的母语和英语距离，控制模型和国家效应。我们使用语系间比较测试语系间的异质性，并报告相应的效应量（Cohen's d）。

**分析4：数字东方主义（距离-优势耦合）。** 为了评估英语优势是否随着与西方社会的文化差异系统性增加，我们检查（i）一个国家在Inglehart-Welzel空间中与英语参考点的文化距离（计算为与使用IVS数据的传统英语国家平均坐标的欧几里得距离）与（ii）该国在文化模仿期间的英语优势之间的关联。我们计算所有非英语母语国家的文化距离与英语优势之间的Pearson和Spearman相关性。这一分析测试更大的跨文化差距是否对应于英语提示下更大的相对收益，与称为*数字东方主义*的结构化区域逆转模式一致。

**分析5：模型来源效应。** 为了评估模型来源是否影响语言效应，我们比较三个模型来源组的英语优势度量：美国开发（n = 10）、中国开发（n = 8）和欧洲开发（n = 3）。对于每个文化区域和语系，我们使用双样本t检验测试平均英语优势在模型来源之间是否不同。这一分析测试模型是否基于其来源显示区域专业化——例如，中国模型对汉藏语系是否比美国模型表现出更弱的英语优势，或者欧洲模型对地理上接近的文化是否显示出更强的母语优势。

**分析6：模型质量分层。** 由于低质量输出可能夸大距离并扭曲相对优势，我们按模型质量进行分层分析。模型质量操作化为每个模型在所有国家和语言中的平均模仿距离（应用响应有效性过滤器后）。我们比较质量层级（基于中位数距离的前50% vs 后50%）之间的英语优势，并使用双样本t检验测试语言效应在高性能模型中是更强还是更弱。我们还排除系统性低质量模型（平均距离>总体平均值3个标准差）并重新计算所有分析以确保稳健性。

**分析7：模型特征。** 我们检查语言效应是否因模型特征而异：（i）模型大小（参数：<10B vs ≥10B），（ii）模型来源（开源vs闭源），以及（iii）模型厂商（OpenAI、Anthropic、Google、Meta、DeepSeek、Alibaba、Mistral）。对于每个特征，我们计算平均英语优势并使用双样本t检验或方差分析测试组间差异。这一分析测试架构或组织因素是否系统性地影响多语言文化表征。

**分析8：稳健性和敏感性。** 我们通过五种敏感性分析评估稳健性：（i）替代距离度量（曼哈顿距离、马氏距离），（ii）替代PCA规格（无旋转、斜旋转、不同数量的成分），（iii）排除异常值（距离>区域平均值2个标准差的国家），（iv）替代模型子集（仅大型模型≥10B参数；排除特定模型家族），以及（v）替代语言分组（地理区域而不是语言家族）。对于每个敏感性分析，我们重新计算英语优势度量并测试区域模式的方向和显著性是否保持一致。如果关键结论在所有或大多数敏感性规格中保持不变，则认为是稳健的。

**效应量和统计报告。** 使用Cohen's d报告组间比较的效应量，使用配对Cohen's d报告组内比较。对于区域分析，我们报告平均差异和标准化效应量。跨模型的一致性量化为显示相同方向效应（例如，给定国家或区域的英语优势> 0）的模型比例。除非另有说明，所有统计检验使用双尾检验，α = 0.05。对于分析集内的多重比较，我们报告未校正的p值，并注明结果是否通过Bonferroni校正。
