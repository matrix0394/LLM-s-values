# 结果（中文版）

## 结果

### LLM价值表达中的基线语言效应

在检查文化角色扮演之前，我们首先通过直接要求23个大型语言模型在六种联合国官方语言（英语、法语、西班牙语、俄语、阿拉伯语和简体中文）中回应10个综合价值观调查（IVS）项目来评估基线价值表达，没有任何文化角色扮演背景（n = 138个模型-语言组合）。这一分析确定提示语言本身是否影响表达的价值观。

在所有语言中，模型聚集在Inglehart-Welzel文化地图的世俗-自我表达象限，表明总体上西方倾向的价值概况。同时，表达的价值观随提示语言显著变化。单因素方差分析显示传统-世俗维度（PC1）上存在显著的语言效应（F = 3.38，p = 0.007），而在生存-自我表达维度（PC2）上未观察到显著效应（F = 0.85，p = 0.52）。英语提示产生最世俗的响应（平均PC1 = +2.69 ± 1.85），而阿拉伯语提示产生最传统的响应（平均PC1 = +0.98 ± 1.49），对应于PC1上1.71个单位的偏移。成对比较证实阿拉伯语提示引发的价值观比所有其他语言更传统（所有p < 0.05）。

语言敏感性在模型之间显著变化。最稳定的模型在语言之间表现出1.69个单位的范围，而最不稳定的表现出5.85个单位的范围。例如，一个模型从用英语提示时的PC1 = -0.70到用中文提示时的PC1 = +4.77，跨越了文化地图上西欧和东亚之间的几乎全部距离。总之，这些结果表明，即使在没有文化角色扮演的情况下，表达的价值取向也强烈依赖于语言。因此，在解释后续分析时考虑了这种基线依赖性。

### 英语国家揭示基线文化偏见

为了在恒定语言条件下建立参考点，我们检查了21个英语国家的文化对齐度，所有国家都使用英语提示进行评估。与预期相反，传统英语国家表现出比几个非洲英语国家更大的文化距离。爱尔兰显示最大距离（3.96），其次是澳大利亚（2.83）、新西兰（2.63）和加拿大（2.63），而尼日利亚（1.03）、加纳（1.32）和卢旺达（1.23）排名最准确表征的国家之列。

偏差模式高度系统化。对于所有传统英语国家，模型表征相对于真实IVS坐标向更世俗和更自我表达的位置偏移。爱尔兰说明了这种模式：尽管其IVS位置适度传统（PC2 = -0.68），模型表征将其置于高度世俗的位置（PC2 = +1.85），对应于2.52个单位的偏移。这种模式与英语训练数据的组成一致，其中不成比例地反映了世俗和进步的观点。这些结果建立了即使在语言保持不变时文化偏差的基线模式。

### 整体语言效应和区域逆转

在用英语和母语评估的66个非英语母语国家中，英语提示平均产生相对于母语提示8.3%的文化距离减少（p < 0.001）。然而，这种总体效应掩盖了显著的跨国变化。个别国家从33.5%的母语优势（瑞士）到27.3%的英语优势（突尼斯）不等。

语言效应的分布强烈不对称，具有长右尾的国家表现出大的英语优势，而相对较少显示类似大的母语优势。当按文化区域对国家进行分组时，出现了明显的区域逆转。非西方地区——包括伊斯兰/阿拉伯、东正教/斯拉夫、西亚和南亚以及儒家社会——显示出一致的英语优势，而西欧国家显示出相反的模式，在母语提示下具有更高的准确性。我们将语言效应中的这种系统性区域逆转称为*数字东方主义*。

### 东亚语言效应的异质性

为了检查这种区域不对称性的潜在机制，我们分析了东亚内部的语言效应，这是一个共享广泛文化传统但在数字生态系统和语言历史方面表现出巨大差异的地区。中国显示出近乎完美的语言平等（+0.07%英语优势）和所有国家中最低的平均文化距离（0.97）。日本（+3.3%）和韩国（+3.0%）同样表现出最小的英语优势。

相比之下，台湾和香港显示出全球观察到的最强英语优势之一（分别为+27.1%和+24.8%）。澳门提供了一个对比案例，表现出强烈的简体中文优势（-13.6%）。这些差异与母语数据可用性和国际英语覆盖范围的变化相吻合，说明了单一文化区域内的显著异质性。

### 超越语系的拉丁美洲变化

拉丁美洲国家同样表现出语言效应的广泛变化，从+20.4%（海地）到-5.2%（巴西）跨越25.6个百分点的范围。海地是该地区唯一的法语国家，显示出最强的英语优势。几个较小的西班牙语国家尽管与西班牙共享语言，也表现出显著的英语优势。

巴西与这种模式不同，显示出母语优势。在整个地区，即使在共享相同语系的国家之间，语言效应也显著变化，表明仅语系不能解释观察到的文化对齐差异。

### 模型来源和区域专业化

为了评估数字东方主义是否反映模型特定的人工制品，我们按来源地区比较了模型。在中国开发的模型对汉藏语系和闪米特语系显示出比在美国开发的模型更弱的英语优势，而欧洲模型对斯拉夫语系显示出强烈的母语优势。同时，所有模型组对某些非西方地区表现出英语优势。

这些结果表明，模型来源有助于文化表征中的区域专业化，但不能消除观察到的语言效应中的区域不对称性。

### 效应的一致性和稳健性

语言效应中的区域逆转在模型之间被证明是高度一致的。21个模型中的19个（90%）对伊斯兰国家显示出相同方向的语言效应，在英语提示下具有更高的准确性。绝对性能在模型之间变化，但语言效应的方向独立于整体模型准确性。

效应量很大。西方和非西方地区之间的对比产生了1.43的Cohen's d。排除异常值、改变PCA规格以及将分析限制在模型子集都产生了可比较的结果。总之，这些分析表明数字东方主义是当前大型语言模型中一个大的、一致的和稳健的模式。

### 研究4. 殖民历史与当代语言效应

我们进行了探索性分析，测试历史殖民关系是否预测LLM文化表征中的当代语言效应。尽管有理论动机的假说，我们发现系统性殖民历史效应的证据有限，突显了检测当代AI系统中历史影响的挑战。

**实验4a：香港vs澳门比较。** 我们比较了香港（英国殖民地1842-1997）的英语优势与澳门（葡萄牙殖民地1557-1999）的葡萄牙语优势。香港显示出正的英语优势（M = 15.84%，95% CI [−62.08, 93.76]），表明平均而言英语提示下的对齐优于中文提示。相比之下，澳门显示出负的葡萄牙语优势（M = −15.67%，95% CI [−90.35, 59.01]），表明中文提示下的对齐优于葡萄牙语提示（图S7B）。

然而，香港和澳门之间的差异在统计上不显著（t(37.9) = 0.509，p = 0.614，Cohen's d = 0.161）。大的置信区间和可忽略的效应量反映了跨模型的显著方差（香港SD = 179.23%；澳门SD = 170.37%），个别模型显示出高度不一致的模式。这种高方差阻止了检测系统性殖民语言效应，尽管有理论动机的比较。

**实验4b：拉丁美洲语言变体。** 我们比较了具有不同殖民语言的拉丁美洲国家的英语优势：西班牙语国家（n = 11，M = 5.43%，SD = 10.17%）、葡萄牙语的巴西（M = 3.58%）和法语的海地（M = 20.38%）。单因素方差分析显示组间无显著差异（F(2, 10) = 1.035，p = 0.391，η² = 0.171）（图S7C）。尽管效应量较大（η² = 0.171），葡萄牙语（n = 1）和法语（n = 1）国家的小样本量限制了检测差异的统计功效。

**实验4c：非洲殖民历史（数据限制）。** 我们尝试比较有和没有英国殖民历史的非洲国家的英语优势。然而，我们发现数据集中所有英国殖民的非洲国家（肯尼亚、尼日利亚、加纳、南非、津巴布韦、赞比亚）仅有英语数据，缺乏计算英语优势所需的母语比较（斯瓦希里语、约鲁巴语、阿坎语、祖鲁语、绍纳语、本巴语）（图S7D）。

这一数据限制反映了多语言AI评估中的系统性差距：由于殖民历史而将英语作为官方语言的国家通常仅用英语评估，阻止了对母语表征的评估。这阻止了计划的分析，并突显了需要更全面的多语言评估数据集，包括以前殖民地区的母语。

**总结。** 我们的探索性分析发现LLMs当代语言表征中系统性殖民历史效应的证据有限。零发现可能反映：(1) 训练数据中真正缺乏殖民遗产效应，(2) 跨模型的高方差掩盖了系统性模式，(3) 由于小样本量导致的统计功效不足，或(4) 殖民效应由我们无法控制的当代因素（例如，当前英语使用、互联网内容分布）中介。具有更大模型样本、当代语言实践控制变量和更全面多语言数据集的未来研究可能更好地定位以检测殖民历史效应。

### 结果总结

总之，这些结果展示了大型语言模型如何跨语言表征文化价值观的系统性区域不对称性。非西方文化在英语提示下更准确地被表征，而西欧文化在母语提示下显示出更高的准确性。这种模式在模型、区域和分析规格中是一致的，将数字东方主义确立为一个稳健的实证现象。研究4对殖民历史效应的探索性分析揭示了方法学挑战和数据限制，为AI系统中历史影响的未来研究提供信息。
