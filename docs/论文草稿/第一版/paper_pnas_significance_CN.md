# 意义陈述（PNAS格式）

**字数：118/120**

随着人工智能系统嵌入全球通信，它们理解和表征多元文化的能力对于公平的技术部署变得至关重要。本研究揭示了大型语言模型编码文化知识的根本不对称性：它们通过英语比通过母语更准确地表征非西方文化，而西方文化则相反。这种"数字东方主义"表明AI系统继承并可能放大历史知识生产模式，其中非西方社会主要通过西方语言框架被理解。我们的发现对AI安全、跨文化交流和数字公平具有直接影响，表明仅靠语言翻译无法确保文化上适当的AI回应。解决这种偏见需要从根本上改变多语言AI系统的训练和评估方式。

## 替代版本（更侧重政策）

**字数：120/120**

全球数十亿人用母语与AI系统互动，但我们表明这些系统用英语比用当地语言更好地理解非西方文化——这种模式我们称之为"数字东方主义"。这种不对称揭示了AI训练数据组成如何塑造文化表征，非西方社会主要通过英语来源编码。这一发现挑战了全球AI部署的基本假设：将界面翻译成当地语言并不能保证文化上适当的回应。对于政策制定者，这突显了多语言训练数据标准的需求；对于AI开发者，这表明文化能力需要的不仅仅是翻译；对于用户，这揭示了被宣传为全球可访问的系统中的隐藏偏见。我们的工作提供了第一个量化框架来测量和解决多语言AI中的文化偏见。
