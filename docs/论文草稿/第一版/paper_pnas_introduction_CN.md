# 引言 (PNAS格式 - v3.0)

**目标长度：约850字**

大型语言模型（LLM）已经从研究原型迅速发展成为全球通信基础设施，数十亿用户通过数十种语言与ChatGPT、Claude和Gemini等系统交互(1)。随着这些模型中介跨文化交流、提供本地化信息并在全球范围内塑造公共话语，一个关键问题出现了：LLM是否在所有语言中同样好地理解多元文化，还是其训练数据中的语言不对称性在文化表征中创造了系统性偏见？

这个问题具有理论和实践意义。从理论上讲，它探讨了人工系统中语言与文化知识之间的关系——这是语言人类学中关于语言是否塑造思想(2)以及文化知识如何跨语言边界传播(3)的长期辩论的计算类比。从实践上讲，它对AI系统的公平部署具有直接影响：如果模型在特定语言中更准确地表征某些文化，这可能延续甚至放大知识生产和文化表征中现有的全球不平等。

## 东方主义假说

爱德华·萨义德的开创性著作《东方主义》(4)记录了西方学术如何主要通过西方语言和视角将"东方"构建为异国情调、落后和单一的他者。萨义德认为，这种知识生产模式不仅仅是描述性的，而是构成性的——它塑造了非西方社会如何被理解、治理和在全球话语中被表征。关键的是，萨义德观察到，东方经常用欧洲语言而不是通过本土声音和文本来描述和分析，在文化表征中创造了根本的不对称性。

我们假设当代LLM可能表现出一种"数字东方主义"形式：因为这些模型主要在英语文本上训练（估计占大多数主要模型训练语料库的80-90%）(5)，它们可能主要通过英语表征编码非西方文化——包括西方学术文献、新闻媒体和关于这些文化的在线讨论，而不是来自这些社会的真实文化生产。如果这个假设成立，我们预期LLM在用英语提示时比用母语提示时更准确地表征非西方文化，尽管直觉上期望母语应该提供更丰富的文化背景。

然而，我们必须首先确定语言本身是否影响模型表达价值观，独立于文化角色扮演。如果提示语言系统性地改变模型响应——例如，如果英语提示始终诱导更世俗或进步的价值观——那么在文化角色扮演中观察到的语言效应可能反映基线语言偏见而不是文化知识的真正差异。

## 研究目标

我们通过对23个最先进LLM的两阶段系统评估来解决这些问题。首先，我们通过在6种联合国语言中测试模型对世界价值观调查问题的回答来评估基线语言效应，不设置任何文化角色扮演背景。其次，我们评估66个国家和13种语言的文化角色扮演准确性。具体来说，我们问：

1. **LLM有内在价值偏见吗，提示语言是否影响表达的价值观？** 我们测量同一模型在不同语言提示时是否表达不同的价值观，即使没有文化角色扮演。这为解释后续文化角色扮演结果建立了基线。

2. **交互语言是否影响LLM的文化表征准确性？** 我们通过让模型用英语和母语扮演特定国家的公民来测量这一点，然后量化模型生成的响应与世界价值观调查的真实文化价值观之间的距离(13)。

3. **这种效应在所有文化中是统一的，还是系统性地变化？** 我们测试语言效应在西方和非西方国家之间，以及在特定文化区域（伊斯兰、东正教、拉丁美洲、东亚、西欧）之间是否不同。我们特别关注区域内部异质性，检查东亚梯度（中国、日本、韩国、台湾、香港、澳门）和拉丁美洲多样性（西班牙语、葡萄牙语和法语国家）等案例。

4. **什么机制可能解释观察到的模式？** 我们检查语言效应与训练数据可用性（从数字生态系统规模估计）、与英语的语言距离、文化区域、殖民历史（香港vs澳门自然实验）、文化软实力（日本和韩国的全球文化输出）、语言变体（欧洲vs拉丁美洲西班牙语/葡萄牙语）和模型来源（美国、中国、欧洲）等因素之间的相关性。

我们的方法结合了跨文化心理学的既定方法（Inglehart-Welzel文化地图框架）(13, 14)和测量LLM文化对齐的新颖计算技术。通过系统地仅改变交互语言而保持所有其他因素不变，我们隔离了语言表征对文化知识的影响。

## 贡献

这项工作做出了四个主要贡献：

**方法论**：我们提供了首次系统评估，结合了基线语言效应评估和跨23个模型、66个国家和13种语言的文化角色扮演测试。这种两阶段设计使我们能够解开基线语言偏见和真正的文化知识差异。

**实证**：我们发现了一个惊人的不对称性，我们称之为"数字东方主义"——非西方文化（伊斯兰+17.4%，东正教+17.7%）在英语中表征更准确，而西方文化（-11.5%）在母语中表征更准确。这种效应非常大（Cohen's d=1.43），在测试的90%模型中一致。关键的是，我们还发现提示语言本身系统性地改变模型价值观（英语诱导世俗价值观，阿拉伯语诱导传统价值观，F=3.38，p=0.007），使文化角色扮演结果的解释变得复杂。

**理论**：我们证明数字东方主义不是统一的，而是由多种机制调节的。训练数据可用性解释了东亚梯度（中国+0.07% vs 台湾+27.1%）。殖民历史解释了香港（+24.8%）vs 澳门（-13.6%）的对比。文化软实力解释了日本和韩国对东方主义的抵抗（+3%）。语言变体解释了拉丁美洲异质性（海地+20.4% vs 巴西-5.2%）。模型来源创造了区域专业化（中国模型汉藏语系+1.9% vs 美国+16.8%）但不消除偏见。这个多机制框架超越了简单的西方vs非西方二分法，揭示了塑造AI文化表征的复杂因素。

**实践**：我们证明仅仅语言翻译不能确保文化适当的AI响应。我们的发现表明需要区域特定的方法：适用于西欧语言的方法可能不适用于东亚、拉丁美洲或非洲背景。我们提供证据表明，多样化模型来源可以减少但不能消除文化偏见，文化软实力和国内数字生态系统可以使非西方文化实现准确的母语表征。反直觉的是，对于许多非西方国家，英语提示目前可能比母语产生更准确的文化表征——这一发现对全球AI部署具有直接影响。
