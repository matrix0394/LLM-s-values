# Stage3 十模型日韩分析 - HTML Slides

## 📋 文件说明

本文件夹包含Stage3十模型（含日韩）分析的HTML presentation slides。

### 核心文件
- **`stage3_ten_models_ja_ko_presentation.html`** - 主演示文件（13 slides）
- **`open_ten_models_presentation.bat`** - Windows打开脚本
- **`open_ten_models_presentation.sh`** - Mac/Linux打开脚本

## 🚀 如何使用

### 方法1: 使用脚本（推荐）

**Windows用户**:
```bash
# 双击运行
open_ten_models_presentation.bat

# 或在终端运行
.\open_ten_models_presentation.bat
```

**Mac/Linux用户**:
```bash
# 添加执行权限（首次）
chmod +x open_ten_models_presentation.sh

# 运行脚本
./open_ten_models_presentation.sh
```

### 方法2: 直接打开

双击 `stage3_ten_models_ja_ko_presentation.html` 文件，在浏览器中打开。

## 🎮 操作指南

### 基本操作
- **←/→ 方向键**: 前后翻页
- **Space**: 下一页
- **ESC**: 进入/退出总览模式
- **F**: 全屏模式
- **Home/End**: 跳到首页/末页

### 高级功能
- **数字键 + Enter**: 跳转到指定页
- **B 或 .**: 暂停（黑屏）
- **S**: 打开演讲者备注（如果有）
