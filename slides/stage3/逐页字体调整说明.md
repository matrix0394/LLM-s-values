## ⚙️ 进一步微调建议

### 如果某一页还是显示不全：

找到对应的 `<section>` 标签，调整 `font-size`:

```html
<!-- 例如：Slide 9 还是太大 -->
<section style="font-size: 0.75em;">  <!-- 改成0.75em，更小 -->
    <h2 style="font-size: 1.5em;">标题</h2>  <!-- 同步调大标题 -->
    ...
</section>
```

### 如果某一页字体太小：

```html
<!-- 例如：Slide 8 字太小 -->
<section style="font-size: 0.95em;">  <!-- 改成0.95em，稍大 -->
    <h2 style="font-size: 1.2em;">标题</h2>
    ...
</section>
```

### 标题大小计算公式：

```
标题相对大小 = 1.5 / section的font-size

例如：
- section = 0.8em → H2应该 = 1.5/0.8 ≈ 1.4em ~ 1.5em
- section = 0.9em → H2应该 = 1.5/0.9 ≈ 1.25em ~ 1.3em
- section = 1.0em → H2应该 = 1.5em（默认）
```

这样可以保持标题在视觉上的大小一致。
