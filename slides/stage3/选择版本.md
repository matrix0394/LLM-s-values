# 选择适合你屏幕的版本

## 📱 现在有两个版本可选

### ✅ 版本1: 标准版（已调整）
**文件**: `stage3_academic_presentation.html`

**适合**:
- 15-16寸笔记本 💻
- 1920×1080 或更高分辨率
- 外接显示器 🖥️

**配置**:
- 基础字体: 28px
- 页面: 1200×800
- 边距: 8%

---

### ⭐ 版本2: 小屏幕版（新）
**文件**: `stage3_academic_presentation_small.html`

**适合**:
- 13-14寸笔记本 💻
- MacBook Air / Pro 13"
- 1440×900 或 1680×1050 分辨率

**配置**:
- 基础字体: **24px** (更小)
- 页面: **1000×900** (更高，显示更多)
- 边距: **10%** (更大边距)
- 图片: 最大400px高度

## 💡 还不够？进一步调整

### 1. 浏览器缩放（最简单）⭐

打开slides后：
```
Cmd + -  (Mac)    缩小
Ctrl + - (Windows) 缩小
```

### 2. 全屏模式

按 **F** 键进入全屏，内容会自动适配。

### 3. 调整浏览器窗口

不要最大化窗口，调整到合适大小，Reveal.js会自动缩放。

---

## 🧪 测试方法

1. **打开slides**
2. 按 **O** 键 - 进入概览模式
3. **查看所有页面** - 是否都完整显示？
4. 按 **Esc** - 返回正常模式
5. **浏览每一页** - 检查底部是否被截断

## 📊 推荐选择

### 如果你的屏幕是：

- **13" MacBook Air/Pro** → 使用 **小屏幕版** ⭐
- **14" 笔记本** → 使用 **小屏幕版** ⭐
- **15" MacBook Pro** → 使用 **标准版**
- **16" 笔记本** → 使用 **标准版**
- **外接显示器** → 使用 **标准版**

## 🎨 其他调整建议

### 如果字体还是太大

编辑你选择的HTML文件，找到：
```css
font-size: 24px; /* 改成 22px 或 20px */
```

### 如果高度不够

在JavaScript配置中：
```javascript
height: 900, /* 改成 1000 或更大 */
```

### 如果某张slide特别拥挤

找到那张slide，添加：
```html
<section style="font-size: 0.85em;">
```
