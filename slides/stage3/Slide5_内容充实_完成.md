### 第一部分：评估标准（上方）

#### 📊 评估标准：文化距离（Cultural Distance）

**左侧**：公式与维度说明
```
Distance = √[(PC1_LLM - PC1_Country)² + (PC2_LLM - PC2_Country)²]

PC1：传统 ↔ 世俗理性价值观（Traditional vs. Secular-Rational）
PC2：生存 ↔ 自我表达价值观（Survival vs. Self-Expression）
```

**右侧**：准确度标准框
```
准确度标准
✓ 距离越小 = 模仿越准确
✗ 距离越大 = 偏离真实文化

优势计算：
优势% = (母语距离 - 英语距离) / 母语距离 × 100%
```

### 第二部分：实验总体结果概览（下方）

#### 左列：统计数据

**全局统计表格**：
| 指标 | 数值 |
|------|------|
| 测试国家数 | 27个 |
| LLM实体数 | 378个（7模型×27国×2语言）|
| 总测试次数 | 37,800次（每实体×10题×5次重复）|

**核心发现预告**（绿色高亮框）：
- **84.6%** 的国家英语表现更好（22/27）
- 平均英语优势：**+12.0%**
- 仅 **4个国家** 母语更好
- 最大英语优势：**中国 47.0%**
- 最大母语优势：秘鲁 24.0%

#### 右列：示例案例

**示例：中国 🇨🇳**

可视化对比：
```
母语（中文）          →          英语
   1.94                        1.03
 文化距离                    文化距离

英语优势：47.0% 🔥
英语距离减少近一半！
```

**💡 这意味着什么？**（黄色提示框）
- ✓ 英语提问时，LLM能更准确地模仿各国文化
- ✗ 母语反而导致偏差增大
- → 完全违背直觉的"英语悖论"！
