## 🎚️ 如果还需要进一步调整

### 方案1: 使用浏览器缩放（最简单）

在展示页面按：
- **Cmd + -** (Mac) 或 **Ctrl + -** (Windows) 缩小
- **Cmd + 0** (Mac) 或 **Ctrl + 0** (Windows) 恢复

### 方案2: 修改基础字体大小

编辑 `stage3_academic_presentation.html`，找到：

```css
.reveal {
    font-family: 'Helvetica Neue', Arial, 'PingFang SC', 'Microsoft YaHei', sans-serif;
    font-size: 28px; /* 这里改成更小，比如 24px 或 26px */
}
```

### 方案3: 调整页面尺寸

在 JavaScript 配置中：

```javascript
Reveal.initialize({
    width: 1200,  // 减小宽度
    height: 800,  // 增加高度
    margin: 0.08, // 增加边距 (0.08 = 8%)
});
```

推荐配置：

| 屏幕类型 | width | height | margin | font-size |
|---------|-------|--------|--------|-----------|
| **小屏幕** (13") | 1000 | 900 | 0.10 | 24px |
| **中屏幕** (15") | 1200 | 800 | 0.08 | 28px ✅ 当前 |
| **大屏幕** (27") | 1400 | 700 | 0.06 | 32px |
