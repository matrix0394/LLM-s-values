# 英语母语国家基准功能 - 使用指南

## 🎯 功能说明

已在多语言分析模块中集成英语母语国家基准距离对比功能，可以计算：

1. **中文中国 距离 真实中国IVS数据**
2. **英文中国 距离 真实中国IVS数据**
3. **英文美国 距离 真实美国IVS数据**（作为基准）

## 📊 分析逻辑

### 距离对比示意图
```
[模型模仿] ←欧氏距离→ [真实IVS数据]

示例：
中文中国模仿 ←距离A→ 真实中国数据
英文中国模仿 ←距离B→ 真实中国数据
英文美国模仿 ←距离C→ 真实美国数据（基准）

分析：
- 如果距离A < 距离B：说明用母语更能准确模仿本国文化
- 距离C 作为基准：英语母语国家的"理想"模仿距离
- 相对基准：距离A/距离C，距离B/距离C
```

### 距离计算公式
```python
distance = sqrt((PC1_model - PC1_real)^2 + (PC2_model - PC2_real)^2)
```

## 🚀 使用方法

### 方法1：运行统一分析脚本

```bash
cd "/Users/yxy/code/LLM's values"
python3 src/roleplay_multilingual/scripts/run_unified_multilingual_analysis.py
```

这个脚本会自动：
1. 加载真实IVS国家数据
2. 加载英文角色扮演数据
3. 加载多语言角色扮演数据（包括en-native）
4. 执行统一PCA分析
5. **计算基准距离对比** ← 新功能
6. 生成可视化和报告

### 方法2：在代码中使用

```python
from src.roleplay_multilingual.unified_multilingual_pca_analysis import UnifiedMultilingualPCAAnalysis

# 创建分析器
analyzer = UnifiedMultilingualPCAAnalysis()

# 运行完整分析（包含基准距离计算）
result = analyzer.run_unified_analysis()

# 查看基准距离对比结果
if result["success"]:
    baseline_results = result["distance_results"].get("baseline_comparison")
    
    if baseline_results:
        # 英语母语国家基准
        print("英语母语国家基准：")
        for key, data in baseline_results["english_native_baseline"].items():
            print(f"{data['country']}: {data['distance']:.3f}")
        
        # 本国语言距离
        print("\n本国语言距离：")
        for key, data in baseline_results["native_language_distances"].items():
            print(f"{data['country']} ({data['language']}): {data['distance']:.3f}")
        
        # 英文距离
        print("\n英文距离：")
        for key, data in baseline_results["english_distances"].items():
            print(f"{data['country']} (en): {data['distance']:.3f}")
        
        # 对比分析
        print("\n对比分析：")
        for country, comparison in baseline_results["comparison"].items():
            if isinstance(comparison, dict) and "native_language_avg_distance" in comparison:
                print(f"\n{country}:")
                print(f"  本国语言: {comparison['native_language_avg_distance']:.3f}")
                print(f"  英文: {comparison['english_avg_distance']:.3f}")
                print(f"  差异: {comparison['difference']:+.3f}")
```

### 结果解读

- **基准距离（0.134）**：英语母语国家模仿自己的理想距离
- **相对基准倍数**：
  - `1.0x` = 与基准相同（理想）
  - `>1.0x` = 比基准差（距离更远）
  - 例如`1.75x`表示距离是基准的1.75倍

- **差异为正（+）**：英文距离 > 本国语言距离
  - 说明用本国语言更准确模仿本国文化
  
- **差异为负（-）**：英文距离 < 本国语言距离
  - 说明用英文反而更接近本国文化（罕见情况）

## ⚠️ 注意事项

### 数据要求

1. **必须有真实IVS国家数据**
   - 路径：`data/processed/ivs_df.pkl`
   - 包含目标国家的真实调查数据

2. **必须有多语言访谈数据**
   - 包含en-native语言的访谈结果
   - 包含native language（zh-cn, ru, es, ar）的访谈结果
   - 包含en语言的访谈结果

3. **国家名称必须完全匹配**
   - 使用官方全称，如"United States of America (the)"
   - 与`config/country_codes.json`保持一致

### 常见问题

**Q: 为什么某些国家没有基准距离？**  
A: 可能原因：
- 该国家没有进行en-native语言的访谈
- 真实IVS数据中缺少该国家
- 国家名称不匹配

**Q: 基准距离多少算正常？**  
A: 一般情况：
- `0.1-0.2`: 非常接近，模仿效果好
- `0.2-0.3`: 较接近，模仿效果尚可
- `>0.3`: 距离较远，模仿效果一般

## 🔬 研究应用

### 1. 多语言悖论验证
```python
# 假设分析结果
china_zh_distance = 0.234  # 中文中国距离
china_en_distance = 0.289  # 英文中国距离
baseline = 0.134            # 英文美国基准

# 分析
if china_zh_distance < china_en_distance:
    print("✅ 验证：用母语更能准确模仿本国文化")
    print(f"   改进幅度: {(china_en_distance - china_zh_distance) / china_en_distance * 100:.1f}%")
```

### 2. 跨文化对比
```python
# 比较不同国家的模仿准确度
countries = ["China", "Russia", "Mexico", "Egypt"]
for country in countries:
    relative_accuracy = baseline / native_distance[country]
    print(f"{country}: {relative_accuracy:.2f}x (相对于基准)")
```

### 3. 语言效应量化
```python
# 量化语言切换的影响
language_effect = english_distance - native_distance
effect_size = language_effect / baseline  # 归一化到基准
print(f"语言效应大小: {effect_size:.2f}个基准单位")
```
