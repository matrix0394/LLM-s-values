# 英语母语国家基准功能 - 更新说明

## 📅 更新日期
2025-01-20

## ✨ 功能概述

在多语言模块中新增了**英语母语国家**作为英文文化距离的基准参考功能。这使得我们可以更准确地评估其他国家用英文回答时的文化差异。

## 🎯 核心价值

### 问题背景
在之前的多语言实验中，我们发现：
- 中国用中文回答 vs 中国用英文回答 → 存在文化距离
- 但缺乏"真正的英文文化基准"来衡量这个距离

### 解决方案
添加英语母语国家（美国、英国、澳大利亚、加拿大、新西兰）作为基准：
- 这些国家代表"真正的英文文化"
- 可以计算其他国家用英文回答时与英文文化的距离
- 更科学地评估"多语言悖论"现象

## 📊 配置详情

### 新增国家（5个）

| 国家 | 代码 | 文化区域 | 特点 |
|------|------|----------|------|
| 美国 | USA (840) | English-Speaking | 多元化，重视自由、民主、创新 |
| 英国 | GBR (826) | English-Speaking | 英语发源地，重视传统、议会民主 |
| 澳大利亚 | AUS (36) | English-Speaking | 平等主义、"公平竞争" |
| 加拿大 | CAN (124) | English-Speaking | 双语多元，重视包容性 |
| 新西兰 | NZL (554) | English-Speaking | 平等主义、环保、双文化 |

### 语言标识
- **语言代码**: `en-native` (区别于其他国家的`en`)
- **问题数量**: 10个IVS问题（与其他语言一致）
- **文化区域**: English-Speaking

## 🔬 应用场景

### 1. 文化距离计算
```python
# 计算中国用英文 vs 美国用英文的文化距离
china_en_distance = calculate_distance(
    china_english_responses,
    usa_native_responses
)

# 对比：中国用中文 vs 美国用英文的距离
china_zh_distance = calculate_distance(
    china_chinese_responses,
    usa_native_responses
)

# 分析：语言切换带来的文化距离变化
language_effect = china_en_distance - china_zh_distance
```

### 2. 多语言悖论验证
```
问题：中国用英文回答时，是更接近"中国文化"还是"英文文化"？

对比链：
中国(中文) ←距离A→ 中国(英文) ←距离B→ 美国(英文)

如果 距离B < 距离A：说明语言切换确实让回答更接近英文文化
如果 距离B > 距离A：说明母语文化仍占主导
```

### 3. 基准可视化

- 🔵 蓝色点：原生语言国家
- 🟢 绿色点：同国家用英文
- 🔴 红色点：**英语母语国家（基准）**

## 💡 使用建议

1. **对比分析**: 总是包含英语母语国家作为基准点
2. **文化距离**: 使用美国或英国作为主要基准（样本量大）
3. **可视化**: 在图表中用特殊标记突出英语母语国家
4. **统计分析**: 计算其他国家与基准的平均距离

## 📝 注意事项

1. **国家名称**: 必须使用完整官方名称
   - ✅ "United States of America (the)"
   - ❌ "USA" 或 "United States"

2. **语言区分**: 
   - `en-native`: 英语母语国家
   - `en`: 其他国家用英文回答

3. **成本控制**: 新增5个国家意味着增加约9%的API调用
