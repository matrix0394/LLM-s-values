## 📊 方法论核心内容

### PPCA方法详解

#### 1. 理论基础
```
概率模型：
X = CZ + μ + ε

参数说明：
• C ∈ ℝ^(D×d): 载荷矩阵
• Z ~ N(0, I): d维潜在变量
• ε ~ N(0, σ²I): 高斯噪声
• μ: 数据均值
```

#### 2. EM算法
```
E步：E[Z|X] = (C^T C + σ²I)^(-1) C^T (X - μ)
M步：C_new = X^T E[Z] (E[ZZ^T] + Nσ²I)^(-1)
     σ²_new = (1/ND) Σ ||X - CE[Z]||²
```

#### 3. 缺失数据处理
```
对于缺失位置 (i, j)：
X_ij^missing = (CZ_i)_j + μ_j
```

#### 4. Varimax旋转
```
目标函数：
maximize V = Σ_j [Σ_i L_ij^4 - (Σ_i L_ij^2)^2 / p]
```

#### 5. 主成分缩放
```
PC1_rescaled = 1.81 × PC1 + 0.38
PC2_rescaled = 1.61 × PC2 - 0.01
```

### 文化距离计算详解

#### 1. 欧几里得距离公式
```python
d(A, B) = √[(PC1_A - PC1_B)² + (PC2_A - PC2_B)²]
```

#### 2. Python实现
```python
import numpy as np

def calculate_cultural_distance(entity_a_coords, entity_b_coords):
    pc1_a, pc2_a = entity_a_coords
    pc1_b, pc2_b = entity_b_coords
    
    distance = np.sqrt(
        (pc1_a - pc1_b)**2 + 
        (pc2_a - pc2_b)**2
    )
    
    return distance
```

#### 3. 统计指标
- 平均距离：μ_d = (1/n) Σ d_i
- 标准差：σ_d = √[(1/n) Σ (d_i - μ_d)²]
- 最小/最大距离：min(d_i), max(d_i)
- 中位数距离：median(d_i)

#### PPCA核心循环（ppca.py）
```python
while True:
    Sx = np.linalg.inv(np.eye(d) + CC / ss)
    
    # E-step
    if missing > 0:
        proj = np.dot(X, C.T)
        data[~observed] = proj[~observed]
    X = np.dot(np.dot(data, C), Sx) / ss
    
    # M-step
    XX = np.dot(X.T, X)
    C = np.dot(np.dot(data.T, X), np.linalg.pinv(XX + N * Sx))
    CC = np.dot(C.T, C)
    
    # 检查收敛
    if diff < tol and counter > 5:
        break
```
