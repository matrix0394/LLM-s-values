# 开题报告答辩PPT

## 文件说明

- **开题答辩.html** - 基于Reveal.js的HTML格式答辩PPT

## 使用方法

### 方法1：直接在浏览器中打开
1. 双击 `开题答辩.html` 文件
2. 文件会在默认浏览器中打开
3. 使用键盘方向键或空格键翻页

### 方法2：使用本地服务器（推荐）
```bash
# 在当前目录下启动简单的HTTP服务器
python -m http.server 8000

# 然后在浏览器中访问
# http://localhost:8000/开题答辩.html
```

## PPT结构

### 共6个主要部分，约30页slides：

1. **研究背景及意义** (4页)
   - 研究背景
   - 三重挑战
   - 研究意义

2. **国内外研究现状** (4页)
   - 基础性研究
   - 价值观测量领域
   - 方法学趋势
   - 研究空白

3. **研究内容与目标** (5页)
   - 研究设计：三阶段递进
   - 当前研究规模
   - 三个关键科学问题
   - 初步研究发现（2页）

4. **研究方案设计** (5页)
   - 研究方法体系
   - 技术路线（2页）
   - 核心计算方法
   - 可行性分析

5. **研究创新点** (4页)
   - 三大创新概览
   - 创新点1：可对齐的价值坐标系
   - 创新点2：全球文化模仿实验
   - 创新点3："英语优势"量化指标

6. **研究计划与基础条件** (4页)
   - 前期研究基础
   - 实验条件
   - 研究计划
   - 待完善条件及解决方案

7. **总结与致谢** (2页)

## 操作快捷键

- **空格键 / 方向键右** - 下一页
- **方向键左** - 上一页
- **方向键上/下** - 在垂直slides中导航
- **ESC** - 显示slides概览
- **F** - 全屏模式
- **S** - 演讲者模式（显示备注）
- **B** - 暂停（黑屏）

## 特色功能

- ✅ 响应式设计，自适应不同屏幕尺寸
- ✅ 美观的配色方案和视觉效果
- ✅ 清晰的层次结构和信息组织
- ✅ 数据可视化展示（统计框、进度指示）
- ✅ 支持垂直和水平导航
- ✅ 内置页码显示

## 注意事项

1. 需要联网才能加载Reveal.js库和字体
2. 建议使用Chrome、Firefox或Edge浏览器
3. 演示时建议使用全屏模式（按F键）
4. 可以按ESC查看所有slides的缩略图

## 自定义修改

如需修改内容，直接编辑 `开题答辩.html` 文件：
- 修改文字内容：找到对应的 `<section>` 标签
- 修改颜色：在 `<style>` 部分修改CSS变量
- 添加/删除页面：添加/删除 `<section>` 标签

## 技术栈

- **Reveal.js 4.5.0** - HTML演示框架
- **CSS3** - 样式和动画
- **响应式设计** - 适配各种屏幕尺寸
