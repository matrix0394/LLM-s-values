# Design Document: SI Figures Cleanup

## Overview

本设计文档描述了SI/figures目录整理的技术方案，包括识别重复/过时图片、整合生成脚本、重新生成分析图表的完整流程。

## Data Models

### FigureInfo
```python
@dataclass
class FigureInfo:
    path: Path
    name: str
    category: str  # S1, S2, S3, S4, S5, S6, S7, S8, summary
    format: str    # pdf, png
    size_bytes: int
    modified_date: datetime
    script: Optional[str]
    is_essential: bool
    is_redundant: bool
```

### DuplicatePair
```python
@dataclass
class DuplicatePair:
    figure1: FigureInfo
    figure2: FigureInfo
    reason: str  # "content_overlap", "naming_pattern"
    keep: str    # which one to keep
```

## Correctness Properties

*A property is a characteristic or behavior that should hold true across all valid executions of a system-essentially, a formal statement about what the system should do. Properties serve as the bridge between human-readable specifications and machine-verifiable correctness guarantees.*

Based on the prework analysis, most acceptance criteria are example-based tests for specific file operations and documentation updates. The key correctness properties are:

**Property 1: Script-Figure Mapping Completeness**
*For any* figure in S4-S8 directories, there SHALL exist a corresponding generation script in analysis/si/ that can reproduce that figure.
**Validates: Requirements 2.1, 2.2**

**Property 2: No Duplicate Figures After Cleanup**
*For any* two figures in the final SI/figures/ structure, they SHALL NOT contain semantically identical content (e.g., S8B and Sx3 cannot both exist). Note: S7A, S7B, S7C are NOT duplicates as they serve different analytical purposes.
**Validates: Requirements 3.1, 3.2, 3.3**

**Property 3: Data Freshness**
*For any* regenerated figure, the underlying data source SHALL have a modification date no earlier than the PCA coordinate files (2026-01-03).
**Validates: Requirements 6.1, 6.2, 6.3**

**Property 4: Style Consistency**
*For any* generation script in analysis/si/, it SHALL import color and style definitions from si_config.py.
**Validates: Requirements 5.2**

## Error Handling

1. **Missing Data Files**: If PCA or analysis data files are missing, scripts SHALL raise FileNotFoundError with clear message
2. **Permission Errors**: If figure files are locked, scripts SHALL skip and log warning
3. **Script Failures**: If a generation script fails, the cleanup process SHALL continue with remaining scripts

## Testing Strategy

### Unit Tests
- Test figure scanning function with mock directory
- Test duplicate detection with known duplicate pairs
- Test script mapping with known figure-script pairs

### Integration Tests
- Test full cleanup workflow on a subset of figures
- Verify documentation updates are consistent

### Manual Verification
- Visual inspection of regenerated figures
- Cross-reference with PNAS requirements

## Implementation Plan

### Phase 1: Audit and Mapping
1. Create audit script to scan SI/figures/
2. Generate figure inventory report
3. Document script-figure mappings

### Phase 2: Script Consolidation
1. Create wrapper scripts in analysis/si/ for S4-S8
2. Ensure all scripts use si_config.py
3. Test each script individually

### Phase 3: Data Refresh
1. Verify PCA data freshness
2. Regenerate stage0_vs_stage3 analysis if needed
3. Regenerate cultural_distance_analysis.csv if needed

### Phase 4: Figure Regeneration
1. Run all generation scripts
2. Verify output files exist
3. Compare with previous versions

### Phase 5: Cleanup and Documentation
1. Remove identified redundant figures
2. Update README.md, PNAS_RECOMMENDED_FIGURES.md
3. Update PNAS_SI_FINAL_STRUCTURE.md with final counts
